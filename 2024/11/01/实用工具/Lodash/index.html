这篇是 Lodash 常用方法的速查表，按「生成 ID / 数组范围 / 对象操作 / 判断与取值 / 函数控制 / 字符串」分组，方便在处理数据时快速找到对应方法。每条都保留了原始签名和返回结果说明。

背景

只有存在 node_modules，并且引入了 lodash 的内置插件包，才可以使用这些方法。

第 1 步：生成唯一 ID

uniqueId('prefix') 返回的是一个带前缀的自增 id。

第 2 步：把路径字符串转成数组

toPath('[6],4, [f[45[5]]],f,2') 把字符串里的属性返回成数组，适合两个深层数组合并，『对象不行』。

第 3 步：生成数组与数字范围

  • times(n, type | fn)：默认返回一个调用了 n 次的 index 类型的数组。
  • times(3, stubString)：结合 times 创建一个有长度且初始值为空的数组。
  • rangeRight(start默认0, end, 间隔)：返回一个不包括 end 值的 start 到 end 范围内的新数字数组，且是『降序』。
  • range()：返回一个不包括 end 值的 start 到 end 范围内的新数字数组，『升序』。
  • zip([],[],[])：将各个数组相同 index 的元素提取出来，组成一个新数组并返回。
  • unzip()：还原，把 zip 后的数组还原回 zip 前的数组。
  • zipWith(array, fn)/unzipWith(array, fn)：带处理函数的 zip/unzip。
  • without(要检查的数组，要剔除的值)：返回过滤后的新数组。
  • uniq(array)：返回一个去重后的新数组。

第 4 步：操作对象

  • assign(object, [source])：有四个，把对象分配到目标对象上。
  • invert(object)：返回一个键值倒置后的对象，如果有重复的值，后面的值会覆盖前面的值。
  • findKey(object, fn)：在 object 上返回一个符合条件的 key（返回找到的第一个）。
  • findLastKey(object, fn)：在 object 上返回一个符合条件的 key（返回反方向找到的第一个）。
  • for 开头的遍历方法无法保证遍历顺序；方法名带 In 的版本会遍历到原型链上。

第 5 步：判断与取值

  • isEqual(value, other)：执行深比较确定两者的值是否相等，不管是对象还是数组都可以比较，适用于判断是否编辑过。
  • defaultTo(value, defaultValue)：如果 value 为 NaN、null 或者 undefined，那么返回 defaultValue。
  • constant(value)：创建一个值，返回新的『常量函数』。
  • castArray(value)：强制转为数组，返回转换后的数组。

第 6 步：控制函数执行

overSome 返回的是带有返回条件的新函数，传入数组后会逐个条件判断：

map 可以配合 methodOf 调用对象上的方法，返回新的结果：

throttle(要节流的函数, [wait=节流的毫秒，默认为0], [options=]) 用于节流：

  • options.leading = true：指定调用在节流开始前。
  • options.trailing = true：指定调用在节流结束后。

chain(value) 启用显式链模式，解除时用 value()。

第 7 步：填充字符串

pad(要填充的字符串, 填充长度, 填充的字符)：字符串长度小于填充长度时，左右平均填充；不平均时截断超出的部分。

注意点

  • array.at() 是原生数组方法，不属于 Lodash，使用前确认运行环境是否支持。
  • overSome、methodOf 示例中的「返回结果」「object」都是占位符，需要替换成真实的函数和对象。
