这篇是 Three.js 入门的总览笔记：先用五步跑通一个可旋转的立方体，再补上父子层级、事件监听、GUI 调试、几何体顶点、材质与贴图、雾和模型加载这些后面每个案例都会用到的知识点。代码可以按顺序直接往同一个页面里加。

背景与素材

做 3D 内容不只需要写代码，素材和工具也要提前准备。下面这些可以参考：

  • Blender：制作 3D 文字
  • 科大讯飞星火：生成故事单元剧情
  • Blockade Labs：根据故事情节生成全景图片（要使用英文单词）
  • TTS-Vue：生成语音作旁白
  • leiapix：将静态图片生成 3D 图片
  • three.js 官网：官网

一个完整的交互式 2D 故事游戏可以这样组织：将文本、图片、音频、按钮（按钮文本、跳转场景的索引值）、场景旋转的起始和结束、持续时间存放到对象数组中，再按照步骤完成载入图片、页面搭建、监听跳转函数等交互。

导入 three.js 的文件后，就可以开始下面的步骤。

分步骤

第一步：创建场景、相机和渲染器

先把 Three.js 的三件套建好：场景负责装物体，相机决定看到什么，渲染器负责画到页面上。

第二步：创建几何体、材质、网格并加入场景

几何体决定形状，材质决定外观，两者组合成网格后才能被渲染。

第三步：使用世界坐标辅助器和轨道控制器

调整相机位置，加入坐标轴辅助器方便观察方向，再用轨道控制器让鼠标可以旋转、缩放视图。

第四步：渲染函数

渲染函数每帧更新控制器、请求下一帧并渲染场景，调用一次就会持续循环。

第五步：监听窗口的变化

一旦窗口缩小，物体不会自己回到视图中心，需要同步更新渲染器尺寸和相机宽高比。

父子层级与变换

为了看清 position、scale、rotation 在父子层级中的关系，先创建一个父元素网格和一个子元素网格，把子元素加到父元素里。

position

  • 子元素的坐标轴相对于父元素。
  • 父元素的 position 设置的是它的局部坐标；没有父元素时，元素设置的 position 就是世界坐标。

scale

  • 对于缩放，不管子元素原本的大小是什么，只要父元素缩放，子元素也会跟着缩放。
  • 公式：父元素缩放为 (x, y, z)，子元素缩放为 (x1, y1, z1)，最终子元素的缩放为 (x*x1, y*y1, z*z1)。
  • 所以，如果遇到与缩放有关的需求，只需要缩放父元素。

rotation

  • rotation 是欧拉角 (x, y, z, xyz)，旋转顺序不同，效果不一样，默认旋转顺序为 xyz。
  • 旋转同样都是相对于父元素。

结果

  • 此时父元素的坐标为 (-3, 0, 0)，而子元素相对于父元素的坐标为 (0, 0, 0)，位于原点。
  • 此时父元素的大小放大 2 倍，子元素在父元素放大后的基础上再放大 2 倍。
  • 此时父元素绕着 x 轴旋转 45°，子元素相对于父元素再旋转 45°，累计变为 90°。

几何体是怎么来的

在 JS 中所有的图形都是由三角形组成的，创建几何体有两种方式。

第一种：顶点逐个列出，不可共用

这种方式每个三角形都单独列出三个顶点，数据有冗余。

第二种：顶点可以共用

只列四个顶点，再用索引指定三角形由哪几个顶点组成，顶点数据可以复用。

网格基础材质与各种贴图

这一节的概念可以对照编辑器里的效果理解。

贴图 / Map

如果使用一张带纹理的 png 图片，边缘透明，贴在一个正/长方形上，边缘也会自动生成纹理；勾选上透明性后边缘纹理即消失。

透明贴图 / alpha Map

使用一张由黑色、白色和 0.5 白色组成的图片贴图，则黑色为完全透明，白色完全不透明，0.5 白色为半透明。即在普通贴图之后再使用透明贴图，只看得见白色区域的图、0.5 白色区域的半透明图以及后面的物体。

环境贴图 / env Map

先在上面背景放上一张全景图/环境的图，环境和环境贴图里放上相同的全景图，可以调节反射率。

高光贴图

在环境中，金属的反射亮度，找一张亮一点的图。

光照贴图

贴的图代表光照射进来的颜色。比如光通过玻璃照进来，而玻璃贴了窗纸，窗纸就是这个图，最后呈现的光展示在物体上也要跟环境贴图搭上。

注意点

  • GUI 示例里的 eventObj 没有定义，需要传入一个包含 Fullscreen、ExitFullscreen 方法的对象。
  • geometry.setIndex(new THREE.BufferAttribute(indices,1)) 也可以直接写成 geometry.setIndex(indices)，两种写法都能用。
  • 模型路径 ../../public/... 是相对路径，实际项目里通常由打包工具处理静态资源，路径要按项目结构调整。
  • 全屏按钮示例中，document.body.requestFullscreen() 会让整个页面全屏，所以按钮也一起被全屏；注释里提到的 renderer.domElement.requestFullscreen() 是只让画布全屏的写法。
