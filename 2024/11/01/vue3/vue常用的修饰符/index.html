结论先行：修饰符是写在指令后面的“小开关”，作用是省掉模板里手写的 event.preventDefault()、event.stopPropagation()、.trim() 这类样板代码。Vue3 的修饰符按用途分成五类：表单修饰符（.lazy、.trim、.number）、事件修饰符（.stop、.prevent、.self、.once、.capture、.passive）、鼠标按键修饰符（.left、.right、.middle）、键盘修饰符（.enter、.esc、.ctrl 等，配合 .exact）、以及 v-model 参数与 v-bind 修饰符（v-model:propName、.camel、.prop、.attr）。下面按类给出写法和场景。

背景：修饰符解决什么问题

填写表单用得最多的是 input 标签，指令用得最多的是 v-model；事件处理则绕不开冒泡、默认行为、触发次数这些细节。修饰符把常见处理逻辑收敛成后缀，既少写代码，也避免每处都重复写事件对象操作。

Vue3 的修饰符基本沿用 Vue2 的语义，但有两处明显变化：

  • .native 被移除：组件未声明为 props 的属性和事件会自动透传到根元素，不再需要修饰符；
  • .sync 被移除：改用带参数的 v-model:propName 实现“prop 双向绑定”。

步骤 1：表单修饰符

lazy

在 change 事件之后才同步值，而不是每次 input 都同步。

填完信息、光标离开标签后，才将值赋给 value，也就是 change 事件之后再进行信息同步。

trim

自动过滤输入的首尾空格字符，中间的空格不会过滤。

number

自动将用户的输入值转为数值类型；如果这个值无法被 parseFloat 解析，则会返回原来的值。输入框使用 type="number" 时浏览器本身也会做类型转换，两者可以配合使用。

步骤 2：事件修饰符

stop

『阻止事件冒泡』，相当于调用 event.stopPropagation 方法。

prevent

『阻止事件的默认行为』，相当于调用了 event.preventDefault 方法。

self

只当 event.target 是当前元素自身时才触发处理函数，『它不会调用 stopPropagation，事件仍会继续冒泡』。

once

绑定了事件以后『只能触发一次』，第二次就不会触发。

capture

让事件在『捕获阶段』触发，而不是默认的冒泡阶段。它改变的是监听阶段，不是一次性行为。

passive

用于提升滚动性能，告诉浏览器这个处理函数不会调用 preventDefault。下面把它加在滚动监听上。

  • 不要把 .passive 和 .prevent 一起使用，因为 .prevent 将会被忽略
  • 在『移动端』，当我们在『监听元素滚动事件的时候，会一直触发 onscroll』，事件会让网页变卡，因此使用这个修饰符时，相当于给 onscroll 事件加了一个“不阻塞”的标记

exact

系统修饰符默认是“包含”语义：@click.ctrl 在同时按下 Ctrl 和 Shift 时也会触发。加上 .exact 后，只有精确按下指定的键才会触发。

组件事件透传（替代 .native）

Vue3 移除了 .native。组件上未声明为 props 的属性与事件会作为『透传 attribute（fallthrough attrs）』自动绑定到根元素上，class 和 style 还会与根元素自身的值合并。

如果一个组件有多个根节点，或需要手动控制透传位置，用 inheritAttrs: false + v-bind="$attrs"（组合式 API 中用 useAttrs()）。

步骤 3：使用鼠标按键与键盘修饰符

鼠标按键修饰符

  • left：左键点击
  • right：右键点击
  • middle：中键点击

键盘修饰符

键盘修饰符用来修饰键盘事件（onkeyup、onkeydown）。

  • 普通键：enter、tab、delete、space、esc、up、down、left、right
  • 系统修饰符：ctrl、alt、meta、shift
  • .exact：精确匹配已按下的系统修饰键

步骤 4：使用 v-model 参数与 v-bind 修饰符

v-model 参数（替代 .sync）

.sync 在 Vue3 中已移除，对应写法是带参数的 v-model:propName：父组件用 v-model:propName 绑定，子组件通过 update:propName 事件回传新值。

子组件声明对应的 prop 和事件，在需要更新时触发 update:myMessage 事件，把新值回传给父组件。

注意：

  • 事件名必须是 update: 加上 prop 名，模板中写成 kebab-case（v-model:my-message），脚本中写成 camelCase（update:myMessage）
  • 一个组件上可以使用多个 v-model:xxx，分别绑定不同的 prop
  • Vue 3.4+ 可以用 defineModel() 简化声明，defineModel('myMessage') 会自动生成 prop 和对应的 update 事件

多个 v-model

对应子组件声明 first-name、last-name 两个 prop，以及 update:firstName、update:lastName 两个事件。

自定义 v-model 修饰符

父组件在 v-model 后追加修饰符，子组件通过 defineModel 的第二个返回值或 xxxModifiers prop 读取。

camel

将命名变为驼峰命名法（viewBox），常用于 SVG 属性。

prop

强制把绑定值设置为 DOM property，而不是 attribute，适合 value、checked、innerHTML 这类 property。

attr

与 .prop 相反，强制把绑定值设置为 attribute。

注意点

  1. .passive 和 .lazy 不是一回事：.passive 表示不阻塞滚动，.lazy 表示把 v-model 的同步时机从 input 推迟到 change。
  2. .self 只在 event.target 为自身时触发，它并不会调用 stopPropagation，事件仍会继续冒泡。
  3. .capture 改变的是监听阶段（捕获阶段），不是“从顶层开始触发”这种一次性行为；事件修饰符的顺序会影响最终行为。
  4. .number 依赖 parseFloat 解析失败时回退原值，输入框本身是 type="number" 时浏览器也会做一次类型转换。
  5. v-model 的父子写法在真实项目中分别位于两个组件文件：父组件模板用 v-model:propName，子组件用 defineProps + emit('update:propName') 或 defineModel。
