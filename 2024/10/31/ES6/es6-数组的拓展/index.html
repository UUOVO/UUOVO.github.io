数组的拓展大致分三类：把类数组或可迭代对象转成数组（...、Array.from、Array.of）、原地改写与查找（copyWithin、fill、find 系列）、以及不修改原数组的复制版方法（toReversed、toSorted、toSpliced、with）；此外 flat / flatMap 负责扁平化，group / groupToMap 负责分组。下面每个方法给一句行为说明、一到两个示例和一句注意点，示例结果都写在注释里。

背景与约定

文中的”原数组”指调用方法的那个数组本身。标了版本的方法在低版本运行时需要用 core-js 等 polyfill 补齐；findLast、toReversed、with、group 并不是 ES6 的内容，放在这里是为了按”数组拓展”整体查阅。

扩展运算符：…

一句话：把可迭代对象（数组、字符串、Set、Map、arguments 等）展开成逗号分隔的元素序列，常用于函数传参、合并数组和浅拷贝。

注意：扩展运算符只做浅拷贝，元素是对象时新旧数组仍共享同一引用；普通对象不是可迭代对象，不能靠 ... 展开成数组。

Array.from()：转数组

一句话：把类数组对象（有 length 和索引，如 arguments、NodeList）或可迭代对象（字符串、Set、Map）转成真正的数组，第二个参数还能直接做映射。

注意：类数组必须有 length，只有 { 0: 'a' } 会得到 []；第二个参数等价于转完再 map，但只遍历一遍。

Array.of()：将一组值转为数组

一句话：把零散的参数原样收集成数组，避免 new Array(3) 被当成”长度为 3”的坑。

注意：Array.of() 不传参数返回 []，也不会对元素做类型转换。

copyWithin()：

  • Array.copyWithin(定位, 从定位开始读, 停止读) ：复制到定位的位置（原有数据会覆盖），返回修改后的原数组（不是新数组）

一句话：在同一个数组内部把一段元素搬到指定位置，长度不变，属于原地修改。

注意：返回值就是原数组本身而不是新数组，索引可以传负数表示从末尾倒数，end 位置不包含。

find()，findIndex()，findLast()，findLastIndex()

  • find()：找出第一个符合条件的数组成员，没有返undefined
  • findIndex()：找出第一个符合条件的数组成员，没有返-1
  • findLast()：从后面到前面找起
  • findLastIndex()：从后面到前面找起

一句话：四个方法都接收 (当前成员, 索引, 原数组) 回调，返回命中的成员或其下标，找不到时分别返回 undefined 和 -1。

注意：findLast / findLastIndex 是较新的 ES2023 方法，低版本运行时需要 polyfill；find 系列会把空位当作 undefined 处理。

fill(填充数，填充起始位，结束位)给值填充一个数组

一句话：用同一个值覆盖指定区间的元素，原地修改，区间是 [start, end)。

注意：填进数组的是同一个值，填充对象时各元素共享同一引用（new Array(2).fill({}) 的两个元素指向同一个对象）；不传 start 时从 0 开始，不传 end 时到末尾。

toReversed()，toSorted()，toSpliced()，with() — 不改变原数组，而是返回原数组操作后的拷贝

  • toReversed()对应reverse()，用来颠倒数组成员的位置。
  • toSorted()对应sort()，用来对数组成员排序。
  • toSpliced()对应splice()，用来在指定位置，删除指定数量的成员，并插入新成员。
  • with(index, value)对应splice(index, 1, value)，用来将指定位置的成员替换为新的值。

一句话：这四个方法是 reverse / sort / splice / 下标赋值的”复制版”，调用后原数组不动，返回改好的拷贝。

注意：这四个方法属于 ES2023 的 Change Array by Copy 提案，不是 ES6，使用前先确认运行环境或 polyfill 是否支持。

⭐ group()、groupToMap() — 将数组成员分组

一句话：传入分组回调，把成员按返回的键归类，group() 用字符串当键，groupToMap() 用对象当键。

  • group() 按照字符串分组
  • groupToMap() 按照对象分组
  • 示例

⭐ 数组的空位

  • Array(3) // [, , ,] —- 遍历空位识别为undefined
  • Array.from()、扩展运算符（…）、entries()、keys()、values()、find()和findIndex()会将空位处理成undefined。
  • copyWithin()会连空位一起拷贝。
  • fill()会将空位视为正常的数组位置。
  • for…of循环也会遍历空位。
  • map()方法遍历，空位是会跳过的。

一句话：空位表示”这个下标没有值”，和显式的 undefined 不是一回事，各方法对空位的处理并不一致。

注意：执行 fill(undefined) 之后空位就变成真实元素了（0 in arr 为 true）；JSON.stringify(Array(3)) 得到 [null,null,null]。
