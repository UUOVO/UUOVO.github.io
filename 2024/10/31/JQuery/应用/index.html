这篇把 jQuery 放进 7 个真实页面场景里：隔行变色、tab 切换、回到顶部、悬停下拉导航、反选、全选/全不选、表格增删记录。每个场景都按「先讲思路，再给关键代码」的方式组织，可以直接对照自己的页面改造。

背景

下面所有示例都假设页面已经引入 jQuery，并且 DOM 结构按各场景的说明写好。示例只给核心逻辑，样式类的名字需要替换成项目里实际使用的类名。

第 2 步：多 tab 切换

结构上分两块：

  • tab 按钮用 ul>li 实现。
  • 按钮对应的内容区域使用相对定位。
  • 内容区域中有与 li 数量对应的 div，每个 div 都使用绝对定位，固定在按钮切换展示的位置。
  • 给除默认 div 之外的所有 div 加上 display:none。

切换逻辑：

  1. 定义一个变量 index = 0，记录当前显示的内容索引。
  2. 获取内容区域的 div（获取到的是一个数组）。
  3. 给 ul>li 绑定点击事件。
  4. 在回调里拿到点击项对应的 currentIndex。

用 index() 取得当前点击的 li 在兄弟中的下标：

第 3 步：回到顶部

样式上就是一个固定在页面的按钮，点击后回到页面最顶部。

然后用平滑滚动回到顶点：

  1. 读取页面滚动条的 Y 轴坐标，如果偏移 offset 为 0 就直接返回。
  2. 定义滚动的总时长、定时器的间隔，以及每次间隔滚动的距离（offset/(总时长/间隔)）。
  3. 用定时器让 offset -= 每次间隔滚动的长度：如果 offset<=0，则令 offset=0 并清除定时器；如果 offset>0，执行 $('html,body').scrollTop(offset)。

  3. 使用 hover 事件，分别给两个回调添加下滑和上滑的动画效果。

注意点

  • 隔行变色用 attr('class', ...) 会覆盖行上原有的 class；如果行本身已有其他类名，改用 addClass() 更安全。
