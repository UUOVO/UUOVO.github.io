这篇用「两条轴」的心智模型讲清 Flex：先确定主轴，再用 justify-content 沿主轴分配空间、用 align-items 沿交叉轴对齐，最后用 flex 控制单个项目的伸缩。结论：方向、换行、对齐三组属性各管一件事，记住主轴与交叉轴就不会混；文末还给出格子数量不定时处理最后一行边距的选择器写法。

  • 10/30
  • 15:29
  • 1.3k

这篇讲清 float 的排列规则，以及它最常带来的高度塌陷，并给出 clear、BFC 和 clearfix 三种处理方式。结论：浮动元素会脱离文档流、不再撑开父元素；只要父元素高度需要包含浮动子元素，就必须清除浮动或开启 BFC，其中 clearfix 是最省事、兼容性也好的写法。

Html-格子布局(Grid)

  • 15:29
  • 2.2k

这篇按「先划格子，再放元素，最后调对齐」的顺序整理 Grid：grid-template-* 负责划分行列，gap 控制间距，grid-row / grid-column 与 grid-area 负责定位，justify-* / align-* 负责对齐。结论：Grid 是二维布局，先确定轨道（行和列），再把元素放进指定的网格线或区域，比用 float 拼布局更直观。
