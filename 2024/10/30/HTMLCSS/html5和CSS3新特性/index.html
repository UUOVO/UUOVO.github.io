HTML5 的语义化指的是『合理正确地使用语义化的标签』来创建页面结构。这篇把 HTML5 与 CSS3 的新特性清单、语义化标签、input 的新增 type、表单的新增属性集中整理成一份速查表，写页面结构时可以直接对照取用。

背景：新特性解决什么问题

HTML5 之前，页面结构全靠 div 堆叠，浏览器和搜索引擎无法判断哪一块是导航、哪一块是正文；表单校验也要靠 JS 手写。HTML5 用语义化标签补齐了结构含义，用新的 type 和表单属性把一部分校验交给了浏览器原生实现，CSS3 则补上了选择器、计算函数和过渡动画。

  • 多媒体标签（audio、video）点击，页面最底部

第二步：用语义化标签搭页面结构

语义化标签按页面区域划分职责：

  • header：头部标签
  • nav：导航栏标签
  • main：创建网页的主体
  • article：内容标签
  • section：定义文档某个区域
  • aside：侧边栏标签
  • footer：底部标签

第四步：使用表单的新增属性

这些属性直接写在表单控件上，触发浏览器自带的校验与交互：

属性值 说明 示例
required 必填
autofocus 页面加载完自动聚焦指定表单
autocomplete: on/off 浏览器基于之前键入的值，默认显示已填写的选项，只有name+成功提交才算键入过
placeholder:"" 文本提示，value有值则不显示
multiple 多选文件提交

注意点

  1. calc() 里参与运算的 +、- 两侧必须有空格，否则是无效值。
  2. autocomplete 的说明里”只有 name + 成功提交才算键入过”，指的是浏览器需要控件有 name 且真实提交过，才会记住该输入值。
  3. 语义化标签在旧版浏览器中默认按行内元素渲染，需要 CSS 补 display: block；现代浏览器已内置该样式。
  4. input 新 type 的约束是浏览器原生行为，可以被绕过，涉及安全与业务规则时服务端仍要再校验。
