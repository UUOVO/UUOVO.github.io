这篇是 ES6 的编码风格清单，覆盖变量声明、字符串、解构、对象字面量、函数参数、数据结构、类与模块、工具链八块。核心只有三条：能用 const 就不写 let；能用声明式写法（解构、扩展运算符、rest 参数、默认值）就不写命令式的赋值和判断；模块统一用 import / export。下面每条给一句规则和一个最小示例，可以照着直接改代码。

背景：为什么要先定风格

ES6 新增的语法大多有”新旧两种写法”，比如 var 与 let/const、+ 拼接与模板字符串、arguments 与 rest 参数。同一项目里混用会带来两类问题：作用域相关的隐蔽 bug，以及 code review 时反复争论写法。先约定规则，再用 ESLint 固化，是最省事的做法。

1. 变量声明：优先 const，需要改再用 let

一句话：块级作用域和上下文会改变的地方用 let；全局常量和不应被重新赋值的引用用 const。

注意：const 只保证”绑定”不变，对象和数组的内容仍然可以修改，const arr = []; arr.push(1) 是合法的。

2. 字符串：静态用单引号或反引号，动态用反引号

一句话：静态字符串一律使用单引号或反引号，需要插值的动态字符串使用反引号。

3. 解构赋值：取成员和多返回值时优先使用

一句话：使用数组/对象成员对变量赋值时，以及函数返回多个值时，优先使用解构赋值。

4. 对象字面量：单行不结尾逗号，多行结尾逗号

一句话：单行定义的对象，最后不以逗号结尾；多行定义的对象，最后以逗号结尾。

注意：多行尾逗号的好处是以后增删属性时 diff 只变动一行，不用连带修改上一行的逗号。

5. 数组：拷贝用扩展运算符，类数组用 Array.from

一句话：使用扩展运算符（...）拷贝数组，使用 Array.from 方法将类数组对象转为数组。

注意：... 拷贝是浅拷贝，元素是对象时新旧数组仍共享引用。

6. 函数：箭头函数、rest 参数、默认值

一句话：立即执行函数可以写成箭头函数的形式，回调和需要固定 this 的场景也优先用箭头函数。

一句话：用箭头函数加 apply 可以替代 Function.prototype.bind。

注意：箭头函数没有自己的 this 和 arguments，所以它继承外层作用域；这也意味着在箭头函数里写 arguments 拿到的是外层的，不是当前函数的。

一句话：所有配置项都应该集中在一个对象里，放在最后一个参数，布尔值不可以直接作为参数。

一句话：不要在函数体内使用 arguments 变量，使用 rest 运算符（...）代替。

一句话：使用默认值语法设置函数参数的默认值，不要在函数体里写判断。

7. 数据结构：键值对用 Map，实体对象用 Object

一句话：key: value 的数据结构使用 Map 结构，模拟现实世界的实体对象时使用 Object。

注意：Map 的键可以是任意类型、有稳定的插入顺序和 size 属性，适合做字典和缓存；Object 适合描述一个有固定字段的实体，便于序列化和解构。

8. 类与模块：class / extends、import / export

一句话：用 class 取代需要操作 prototype 的写法，使用 extends 实现继承。

一句话：用 import 取代 require()、用 export 取代 module.exports；模块只有一个输出值时，使用 export default。输出的函数名首字母应该小写，对象名的首字母应该大写。


9. 工具链：安装并配置 ESLint

一句话：在项目根目录安装 ESLint 和 Airbnb 规则集，然后新建 .eslintrc 指向该规则集。

一句话：配置文件的全部内容就是继承 Airbnb 规则集。

注意：原文把这两段都标成了 js，实际上第一条是终端命令、第二条是 JSON 配置，这里改成了 bash 和 json。另外 ESLint v9 起默认使用扁平配置 eslint.config.js，.eslintrc 需要显式开启兼容模式；如果项目用新版 ESLint，这条配置要按官方迁移指南改写。Airbnb 规则集还要求同时安装 eslint-plugin-import、eslint-plugin-jsx-a11y、eslint-plugin-react 这几个 peer 依赖，第三行命令已包含。

踩坑与注意点

  1. const 约束的是绑定不是值，对象内容依然可变。
  2. 箭头函数没有自己的 this、arguments，不能用作构造函数，也不适合需要动态 this 的方法。
  3. 布尔值直接作为参数（如 divide(10, 2, true)）可读性差，统一改成选项对象。
  4. .eslintrc 只在 ESLint v8 及以前的默认模式下生效，v9 默认使用扁平配置。
