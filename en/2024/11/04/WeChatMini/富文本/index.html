小程序原生的 rich-text 只能把 HTML 渲染出来，很难在渲染后拿到具体节点做二次处理。这篇给出可复现的做法：用 mp-html 渲染富文本，再通过 selectComponent 拿到组件实例，用正则或实例上的图片/视频数组完成处理，最后把结果替换回原 HTML。

背景与场景

后端返回的 HTML 片段通常不能直接使用：图片可能是相对路径或带 thumb 后缀的缩略图，视频标签需要换成自己的播放器，标签之间的文本还可能要单独提取出来做摘要或换行。rich-text 渲染后拿不到这些节点，所以这里选择 mp-html 这类会把节点解析成组件、并对外暴露实例数据的方案。

步骤

1. 引入 mp-html 组件

使用已封装好的 mp-html 组件，它已经处理了图片、视频等节点的渲染，便于高效地开发。可以按文档用 npm 安装，也可以把组件目录拷进项目，下文以本地组件路径为例。

2. 在页面的 json 文件中引入组件

在要使用富文本的页面同名 json 里注册组件。

3. 在 wxml 文件中使用组件

id 用来标识该组件的唯一身份，后面 selectComponent 靠它定位；content 则是把 HTML 代码渲染出来的容器，传入的是 HTML 字符串。

4. 用 selectComponent(‘id’) 获取组件实例

在页面生命周期里用 this.selectComponent('#article') 取实例，注意要等节点渲染完成（onReady 之后）再取，否则可能拿到 null。

5. 为要处理的标签写匹配规则

如果要处理富文本里的某一个标签，就需要有对应的匹配规则，先把目标标签从 HTML 字符串里取出来。

6. 取出单个标签，统一处理后替换回原 HTML

先拿到单个标签，统一做处理，再替换回原来的 HTML 中，这样不会破坏其余结构。

如果只是想让组件内的图片预览、视频播放使用处理后的地址，也可以直接遍历实例上的图片数组/视频数组。

匹配规则

用途 正则 输入 输出
图片标签 /\<(img)[^>]*>/gi <img src="a.png" alt="封面"> ['<img src="a.png" alt="封面">']
视频标签 /<(video)[^>]*>/gi <video src="a.mp4"></video> ['<video src="a.mp4">']
标签之间的文本 /(?<=>)[^>]+(?=<[\/]?\w+.*>)/g <p>你好</p> ['你好']
空白字符 /(\s)/g ' a b ' [' ', ' ', ' ', ' ']（配合 replaceAll 得到 'ab'）

示例

文字换行

后端把多个状态用逗号拼成一个字符串时，渲染前按逗号拆成数组，wxml 里循环就能换行。

去掉字符串文本的空格

用 /(\s)/g 匹配所有空白字符，再整体替换为空字符串。

注意点

  • 标签文本正则用了后行断言 (?<=>)，旧版运行环境（如部分低版本 iOS/Android WebView）并不支持，可能直接抛语法错误。若目标环境不保证支持，可改成捕获组 />([^<]+)</g 再取 $1，具体以真机验证为准。
  • .replace(',', '') 只会去掉第一个逗号，有多个匹配结果时要写成 .replace(/,/g, '') 或直接用 .join('')。
  • as RegExpMatchArray 是 TypeScript 的类型断言，只能写在 .ts 文件里，纯 JS 去掉即可；html.match() 可能返回 null，取值前先兜底 || []。
  • selectComponent 要放在 onReady 之后调用；id 是组件的选择器标识，不是普通 DOM 的 id。
  • String.prototype.replaceAll 需要较新的基础库/运行时，旧环境可退回 replace(reg, '')（正则带 g）。
