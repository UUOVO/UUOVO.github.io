结论先行：复杂度描述的是「数据量 n 变大时，耗时或额外空间的增长趋势」，不是具体跑了多少毫秒。 写法上用大 O 表示，规则只有三条：省略常数、只保留最高阶项、把最高阶项的系数变成 1。判断快慢时记住这个顺序：O(1) < O(log n) < O(n) < O(nlog n) < O(n²)。空间复杂度一般只看「额外」开辟的空间，输入和输出都不算。

背景：为什么要看趋势而不是看耗时

同一段代码在不同机器、不同输入上跑出来的时间差别很大，但增长趋势是稳定的：n 翻一倍时，O(n) 的耗时翻一倍，O(n²) 的耗时翻四倍。抓住趋势，才能在写代码之前判断算法能不能扛住数据量。

第 1 步：理解时间复杂度的定义

含义：若存在函数 f(n)，使得当 n 趋近于无穷大时，T(n)/f(n) 的极限值为不等于零的常数，则称 f(n) 是 T(n) 的同数量级函数。记作 T(n)= O(f(n))，称 O(f(n)) 为算法的渐进时间复杂度，简称时间复杂度。

  • 通过观察一个方法在执行不同的输入情况时，所呈现的结果，并以线段表示趋势，从而得到线性时间复杂度。
  • 简单理解：『一个算法或是一个程序在运行时，所消耗的时间（或者代码被执行的总次数）』。
  • 大 O 表示法：算法的时间复杂度通常用大 O 来表示，其中 T 表示时间，称 O(f(n)) 为算法的渐进时间复杂度。

时间复杂度的数量级，其原则是：

  • 『省略常数』，如果运行时间是常数量级，用常数 1 表示。
  • 『保留最高阶的项』。
  • 『把最高阶项的系数变为 1』。
  • 示例：2n3 + 3n2 + 7 变成 O(n3)。

第 2 步：识别常见的阶

常数阶：O(1)

每次调用方法时，语句执行的次数是固定的（即使有循环，次数也是有限的），其它语句只执行一次，所以为 O(1)。

对数阶：O(log n)

i 的值随 n 成对数增长，即为 log 2n，时间复杂度 T(n) = O(log n)。

线性阶：O(n)

y = f(x)，即 T(n) = O(n)，循环次数与 n 成正比。

线性对数阶：O(nlog n)

归并排序的复杂度就是这样：将对数阶的代码循环 n 遍，即两层循环，但内层循环的次数与外层循环形成对数阶。

平方阶：O(n2)

也是两层循环，但内层循环次数同样与 n 成正比。

总结

当 x 轴 n 的值越来越大时，y 轴耗时的时长为：O(1) < O(log n) < O(n) < O(nlog n) < O(n2)。

第 3 步：理解空间复杂度

一般指额外空间复杂度。看的是定义的变量，『输入数组不算额外空间，输出空间不算额外空间。』使用的额外空间与数据量没有关系就称为 O(1)，表示使用常数量级别的额外空间。

  • 表示的是算法的存储空间和数据之间的关系，即一个算法在运行时，所消耗的空间。
  • 所有值都存储在内存中，而这些值在内存的占用情况、内存泄漏，与空间复杂度无关。
  • 创建一个变量存储值，在每次循环迭代的过程中，这个值会改变，每次改变都是新值，并且随着迭代变大变小。画线看图的整体趋势，得出结果。
算法 空间复杂度 原因
循环 O(1) 操作一个或相同的数，没有“永久”新值产生的迭代
递归 O(n) 为每个嵌套函数调用创建一个新值（接收的参数）
线性搜索 O(1) 迭代期间没有产生“永久”新值
二分查找 O(1) 迭代期间没有产生“永久”的新值
冒泡搜索 O(1) 迭代期间没有产生“永久”的新值
快速排序 O(n) 嵌套函数调用将创建新值
归并排序 O(n) 嵌套函数调用将创建新值

第 4 步：记住空间复杂度的阶

  • 常数阶 O(1)：int i;
  • 线性阶 O(n)：int [] arr;
  • 平方阶 O(n2)：int [][] arr;

踩坑与注意点

  • 复杂度只保留最高阶项，O(2n) 和 O(n + 100) 都写作 O(n)，常数不进入大 O。
  • 并列的两个循环是 O(n + m) 而不是 O(n²)，只有嵌套且都随 n 增长才是 O(n²)。
  • 空间复杂度只看额外开辟的空间，原地排序的额外空间是 O(1)，归并排序需要额外数组所以是 O(n)。
  • 递归的空间复杂度取决于调用栈深度，递归层数与 n 相关时为 O(n)。
