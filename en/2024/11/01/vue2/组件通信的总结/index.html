Vue 组件通信可以按「关系」来选方案：父子之间优先 props / 自定义事件，父组件想调用子组件或拿子组件实例用 ref，跨层级用 $attrs / $listeners，关系说不清时用全局事件总线或 pubsub。本文按父子数据同步 → 父传子 → 子传父 → 跨级 → 万能方案这条顺序整理，每种方式都给出最小写法，方便按场景直接查。

背景：先分清方向

通信的本质只有两件事：数据往下走还是往上走。往下走用 props（或插槽传结构），往上走用事件，横着走（兄弟、跨级）才需要总线和订阅发布。另外，v-model 和 .sync 都是「父子数据同步」的语法糖，理解了它们，后面的写法会顺很多。

第 1 步：父子数据同步

  • v-model 指令，可以收集表单数据（注：v-model 收集 checkbox 需要用数组收集）。
  • 属性修饰符 .sync，可以实现父子数据同步。

第 3 步：子传父

可用手段有四种：

  • 自定义事件。
  • ref：在父组件内部获取子组件。
  • $children：在父组件内部获取全部的子组件，『返回数组』。
  • $parent：在子组件内部获取唯一的父组件，『返回组件实例』。

自定义事件（$emit、$on[简写 @]）

第 4 步：跨级组件通信

  • $attrs：组件实例的属性，可以获取到父亲传递的 props 数据（前提是子组件没有通过 props 接收）。
  • $listeners：组件实例的属性，可以获取到父亲传递的自定义事件（对象形式呈现）。

踩坑与注意点

  • 用 ref 方式绑定自定义事件时，回调必须提前在 methods 中定义或用箭头函数，否则 this 会丢。
  • 自定义事件要在 beforeDestroy 中解绑，全局总线尤其容易忘记，会造成重复触发和内存泄漏。
  • $children 返回数组，顺序不保证；能用 ref 精确定位子组件时优先用 ref。
  • $attrs 取不到已经被 props 声明过的属性，这是它“透传”的前提。
  • 插槽里的 v-slot 只能写在 <template> 上；单标签组件不能承载默认插槽内容。
  • v-model 收集 checkbox 时要用数组收集，否则拿到的是布尔值。
