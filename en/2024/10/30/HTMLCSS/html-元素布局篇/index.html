这篇是一份布局速查：按「水平居中 → 垂直居中 → 水平垂直居中 → 两列 / 三列 / 等分 → Sticky Footer → 全屏」分类，每个场景给出可复制的关键声明。结论：优先用 Flex 或 Grid；需要兼容旧代码时，再用 text-align、margin: auto、绝对定位加 transform 等方案。凡是用到 float 的，父容器都要记得加 clearfix。

通用前提：clearfix

只要布局里用到 float，就先给父容器加上这段 clearfix，避免高度塌陷。

一、水平居中

1. 行内块元素：text-align

子元素先变成行内块元素。

父元素再设置文本居中，行内块子元素就会跟着水平居中。

2. 定宽块级元素：margin: 0 auto

子元素设置自动左右外边距即可。

3. 定宽块级元素：relative + 负 margin

子元素先相对定位到父元素中线，再用负的左边距把自己拉回一半宽度。

4. 定宽块级元素：absolute + left/right 0 + margin auto

父元素需要有定位上下文和明确高度。

子元素左右都设为 0，再用 margin: auto 自动分配剩余空间。

5. 定宽块级元素：absolute + translateX

父元素设置相对定位。

子元素先移到父元素中线，再用 translateX(-50%) 回退自身宽度的一半。

6. Flex

父元素设置 flex 并沿主轴居中。

子元素用自动外边距也可以居中。

7. Grid

把上一条的 display: flex 换成 display: grid，其余写法相同。

二、垂直居中

1. 行内块级元素

父元素设置与自身高度相同的行高。

子元素设为行内块，并让垂直对齐方式为中线。

2. 定位方式一：top 50% + 负 margin

父元素设置相对定位。

子元素先下移父元素高度的一半，再用负的上边距回退自身高度的一半。

3. 定位方式二：top/bottom 0 + margin auto

父元素设置相对定位。

子元素上下都设为 0，再配合固定高度和自动外边距。

4. 定位方式三：translateY

父元素设置相对定位。

子元素先下移一半，再用 translateY(-50%) 回退自身高度的一半。

5. Flex

父元素设置 flex，并沿交叉轴居中。

子元素也可以改用自动外边距。

6. Grid

父元素设置 grid，并沿交叉轴居中。

子元素有三种写法：自动外边距、align-self，或直接由父元素的 align-items 控制。

三、水平垂直居中

1. 行内块级

父元素同时设置行高和文本居中。

子元素设为行内块并垂直对齐中线。

2. 定位方式一：calc

父元素设置相对定位后，子元素用 calc() 同时计算左边和上边的偏移。

3. 定位方式二：left/top 50% + 负 margin

父元素设置相对定位。

子元素先移到父元素中心，再用负外边距回退自身宽高的一半。

4. 定位方式三：四边 0 + margin auto

父元素设置相对定位。

子元素四边都设为 0，再用自动外边距居中。

5. 定位方式四：translate

父元素设置相对定位。

子元素先移到中心，再用 translate(-50%, -50%) 回退自身宽高的一半。

6. Flex

父元素同时在主轴和交叉轴居中。

子元素也可以改用自动外边距。

7. Grid

父元素用 place-items 或 place-content 一次设置两个方向的对齐。

子元素可以用自动外边距或 place-self。

四、两列布局

两列布局：一列定宽（也可能由子元素决定宽度），一列自适应。下面以左列定宽、右列自适应、两列高度一样为例。

1. float + calc

左容器浮动，右容器也浮动，并用 calc() 算出剩余宽度。

限制：左容器宽度不可以由子元素撑起。

2. float + margin-left

左容器浮动，右容器用左外边距让出左列宽度。

右容器用外边距让位：

限制：左容器宽度不可以由子元素撑起。

3. absolute + margin-left

左容器绝对定位，右容器用左外边距让位。

限制：左容器宽度不可以由子元素撑起。

4. float + overflow

左容器浮动，右容器用 overflow: hidden 开启 BFC，自动避开浮动元素。

这种方式没有「左列宽度不能由子元素撑起」的限制。

5. Flex

左右父级容器设置 flex，右容器用 flex: 1 占满剩余空间。

右容器占满剩余空间：

这种方式没有额外限制。

6. Grid

父容器直接划分为「自适应 + 剩余空间」两列。

这种方式没有额外限制。

五、三列布局

1. Float 方式一

左右两列分别浮动，中间列用 overflow: hidden 形成 BFC 占住中间区域。

2. Float 方式二

左右两列浮动，中间列用 calc() 计算剩余宽度。

3. Position

左右两列绝对定位到父容器两侧，中间列用外边距让出两侧宽度。

4. Flex

父容器设置 flex，右容器用 flex: 1 占满剩余宽度。

5. Grid

父容器划分为「自适应 + 剩余 + 自适应」三列。

六、等分布局

1. 浮动 + 百分比

子元素共有类设置 25% 宽度并向左浮动，四列刚好铺满。

2. 行内块级 + 百分比

子元素共有类设为行内块，并用略小于 25% 的宽度给行内块之间的空白留位置。

3. Flex

父容器设置 flex，子元素共有类用 flex: 1 平分空间。

子元素平分剩余空间：

4. Grid

父容器用 repeat(4, 1fr) 直接划出四等分。

七、Sticky Footer 布局

1. 绝对定位

html 和 body 先撑满视口高度。

父级容器设置相对定位并撑满高度。

中间容器预留出底部的高度。

底部绝对定位到父容器底部。

2. calc()

中间容器用 calc() 让最小高度等于视口高度减去底部高度。

3. Flex

父级容器改成纵向 flex，并设置最小高度为视口高度。

中间容器用 flex: 1 占满剩余空间。

4. Grid

父级容器用三行网格，中间行自动占满剩余空间。

八、全屏布局

1. calc()

中间父容器用 calc() 固定高度，并隐藏溢出。

中间左区域撑满高度。

中间右区域独立滚动。

中间右内容器可以设置任意内容高度。

2. Flex

父容器改成纵向 flex。

中间父容器用 flex: 1 占满剩余高度，并独立滚动。

中间右内容器可以设置任意内容高度。

3. Grid

父容器用三行网格。

中间父容器设置自动滚动。

中间右内容器可以设置任意内容高度。

注意点

  • 所有 float 方案都要给父容器加 clearfix，否则会出现高度塌陷。
  • margin: 0 auto 只对定宽块级元素有效；行内元素要用 text-align: center。
  • 绝对定位居中要确保父元素有定位上下文（position: relative），否则会相对视口定位。
  • calc() 的运算符两侧必须有空格，否则整条声明无效。
  • 两列布局里的 float + calc、float + margin-left、absolute + margin-left 都要求左列宽度固定，不能由子元素撑开。
  • 等分布局用 24.5% 是为了给行内块之间的空白留位置；去掉 HTML 空白或改用 flex 更稳妥。
  • 全屏布局里只有「中间右」需要 overflow: auto，其余容器保持固定，否则滚动会落到错误的层级。
