这篇是一份“查得到、抄得走”的 Hook 速查：先用一句话说清 Hook 解决了什么问题，再按「内置 Hook → 请求数据 → react-redux」三类列出常用 API，每个 API 都给出签名与关键参数，最后单独列出容易记错的执行时机。

Hook 本质上就是一个函数，它简化了组件，有自己的状态管理、生命周期管理和状态共享。
Hook API 索引

背景：Hook 解决了什么

  • 组件之间状态复用；
  • 在函数组件中可以使用生命周期；
  • 不区分组件的使用场景（函数组件与 class 组件的能力对齐）。

一、React 内置的 Hook

useState（状态管理）

作用：为组件添加 state，并通过 setState 更新 state，避免重复创建 initialState。

  • setState(设置变量)：更新状态；
  • useState(初始化变量)：声明状态并给出初始值。

注意：setState() 在 React 中『大部分是异步』，但也存在同步的情况：

  • 在 setTimeout 回调函数中调用，会『同步』修改；
  • 在原生 DOM 事件的回调函数中调用，会『同步』修改。

useEffect（生命周期管理）

作用：处理副作用（包括网络请求、直接操作 DOM、使用计时器函数等），相当于 componentDidMount 和 componentDidUpdate。

useLayoutEffect

  • 作用：副作用会在 DOM 更新之后同步执行，会阻塞浏览器绘制；
  • 语法：与 useEffect 一样。

与 useEffect 的区别：

  • useEffect 是『异步』执行，useLayoutEffect 是『同步』执行；
  • useEffect 会在整个页面『渲染完』才调用，而 useLayoutEffect 是在浏览器重新『绘制屏幕之前』触发。

useRef（获取 DOM 操作）

作用：通过 ref 操作 DOM，避免重复创建 ref 的内容。

用法：ref.current = 子组件的实例。

注意点：

  • 『改变 ref.current 属性时，React 不会重新渲染组件』，而 useState 会触发页面的重新渲染；
  • 更新 useRef 是副作用，所以一般写在 useEffect 或事件处理函数里；
  • 使用 useRef 保存不影响组件视图输出的信息，例如清除定时器。

一个常见场景是获取上一次的值。下面的自定义 Hook 每次渲染后把当前值写入 ref，返回的却是上一次渲染时的值。

useImperativeHandle（组件暴露值/方法）

作用：向父组件暴露一个自定义的 ref（穿透 ref），应当与 forwardRef 一起使用（包在 forwardRef 里面）。

  • ref：子组件向父组件暴露的实例；
  • createHandle：函数，返回父组件可操作的实例和方法；
  • dependencies：监听的状态，依赖变化时更新暴露的内容。

useMemo（缓存值）

作用：跳过不必要的计算，优化渲染性能，缓存每次重新渲染都需要计算的结果。

  • 只有依赖改变，才会重新执行；
  • 返回值：初次渲染时，返回不带参数调用计算函数的结果；依赖不变时，返回上次缓存的值；依赖变化时，返回新值。

useCallback（缓存函数）

概念：useMemo 的语法糖，缓存的是一个函数，返回的也是一个函数。

与 useMemo 的区别：

  • useCallback 不会执行第一个参数函数，而是将『函数返回』；
  • useMemo 会执行第一个函数，并且将『结果返回』。

useReducer（redux 相似）

作用：向组件添加一个管理状态的 reducer，实现 reducer 函数，避免重新创建初始值。

  • reducer：更新 state 的纯函数。参数为 state 和 action，返回值是更新后的 state；
  • initialArg：初始化 state 的任意值；
  • init：计算初始值的函数。如果存在，使用 init(initialArg) 的执行结果作为初始值，否则使用 initialArg；
  • dispatch：更新 state 并触发组件重新渲染，用法为 dispatch(newVar)。

三、react-redux 的 hooks

引入方式：import { hook } from 'react-redux'。

useSelector()

从 Redux 的 store 对象中提取数据（state）。

useDispatch()

返回 Redux store 中对 dispatch 函数的引用，即把 dispatch 方法暴露出来使用。

把 dispatch 传递给子组件时，可以先用 useCallback 包一层，再把组件暴露给其它组件使用。

useStore()

返回 Redux Provider 组件的 store 对象的引用。

踩坑与注意点

  • usePrevious 示例在首次渲染时 ref.current 还是 undefined，如果需要首帧就有值，要给它一个初始值。
  • useInfiniteQuery 的 queryKey 会参与缓存，拼错或漏写依赖会导致翻页数据串页。
