这篇把「故障波纹」动效拆成一条可复现的路径：先用模板站生成 feTurbulence + feDisplacementMap 的 SVG 滤镜，再把它挂到目标元素上，最后用 GSAP 时间轴持续修改 baseFrequency，让画面产生抖动的故障感。结论：这类效果优先用 SVG 滤镜实现，CSS 滤镜能力有限，canvas 则要自己处理像素。

背景：实现滤镜的三条路线

  1. canvas：能力最强，但需要自己写绘制与像素处理逻辑。
  2. CSS：功能较弱，复杂滤镜难以表达。
  3. SVG：可以直接用现成的 SVG Filters 模板效果 调参并复制代码。

本文选择第三条路线，用 SVG 滤镜叠加 GSAP 动画。

实现步骤

步骤 1：在模板站生成滤波器

这个效果用到两种 SVG 滤镜：

  • **湍流滤镜 feTurbulence**：基于 Perlin Noise 算法生成噪声，类似连绵起伏的山峰、凹凸不平的地面、大理石纹理、纸张褶皱。
    • type：turbulence（尖锐）或 fractalNoise（柔和），本例选 turbulence。
    • baseFrequency：依次表示横向、纵向频率，取值 0–1，值越小噪声频率越小；本例为 0 0.4。
  • **置换滤镜 feDisplacementMap**：用噪声位移像素。
    • scale：值越大，受噪声影响越大；本例为 40。
参数 作用 本例取值
type 噪声类型，turbulence 尖锐、fractalNoise 柔和 turbulence
baseFrequency 横向、纵向噪声频率，0–1，越小越平缓 0 0.4
scale 位移强度，越大扭曲越明显 40

在模板网站上调到满意效果后，复制生成的 SVG 代码。

步骤 2：把滤镜藏进页面

把复制的代码放进隐藏的 <svg><defs> 中，只保留一个可被引用的 id。

这里本质上只是借用 SVG 的滤镜效果，所以让 SVG 本身不显示；使用时通过滤镜的 id 引用，这个 id 可以自定义。

步骤 3：给目标元素挂上滤镜

在需要应用效果的元素或 class 上写 filter，url() 里的 id 与上一步保持一致。

步骤 4：用 GSAP 让 baseFrequency 动起来

静态滤镜只是扭曲画面，动画的关键在于持续改变 baseFrequency 的值：

  • 使用 GSAP 库修改 feTurbulence 的属性。
  • 主要用 GSAP 的时间轴（timeline）实现：先获取 feTurbulence 选择器，再在 timeline 的回调函数中设置要改变的 key 和 value。
  • 定义一个初始值，通过调用 timeline 控制值的变化与过渡时间。
  • timeline 中先暂停动画，然后获取图片的选择器。
  • 判断图片是否加载完成（complete）：加载完成就调用 play()，否则监听 load 事件，等加载完成后再播放。

注意点

  • baseFrequency 是横向、纵向两个值，只改其中一个方向会让波纹偏向单轴。
  • scale 过大会让图片严重扭曲；40 只是原文示例值，需要按素材调整。
  • 播放动画前先判断图片是否 complete，否则时间轴可能在图片尚未就绪时就开始。
  • timeline 先暂停再手动播放，可以避免页面加载时动画已经跑完。
