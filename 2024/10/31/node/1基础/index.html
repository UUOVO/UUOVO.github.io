这篇把 Node 入门绕不开的四件事串成一条线：命令行怎么操作目录、Node 到底是什么、npm 怎么管理包、CommonJS 怎么引用和暴露模块。读完你应该能独立初始化一个 Node 项目、写出可被 require 的模块，并说清 exports 与 module.exports 的区别；文末的事件示例可以直接当成一个最小的订阅/发布模型来用。

背景：为什么要先熟悉命令行和 Node

平时在浏览器里写 JS，能用的只有 DOM 和 BOM；一旦要读写文件、起服务、跑构建，就必须回到 Node 这一侧。Node 把 JS 从浏览器里解放出来，也因此要求你会用终端定位目录、执行脚本——所以下面先补命令行，再讲 Node 本身。

一、命令行窗口（CMD / 终端 / shell）的常用指令

Windows 下最基础的四条目录操作，先混个眼熟：

  • dir：列出当前目录下的所有文件
  • cd 目录名：进入到指定的目录
  • md 目录名：创建一个文件夹
  • rd 目录名：删除一个文件夹

二、Node.js 是什么

  • 一门后端语言（服务器端的程序语言），能够连接数据库存取数据，能够接受和处理网络请求（服务器的响应，发送请求去获取数据），单线程事件驱动，异步执行、不等待，从而提高 IO（Input/Output）的处理速度和效率
  • Node 是一个对 ES 标准做了实现的 JS 引擎
  • Node 中 JS 引擎使用的是 Chrome 的 V8 引擎
  • Node 仅仅对 ES 标准进行了实现，所以在 Node 中不包含 DOM 和 BOM
  • Node 的特点：
    1. 非阻塞、异步的 I/O
    2. 事件和回调函数
    3. 单线程（主线程单线程，后台有 I/O 线程池）
    4. 跨平台

注意：说 Node 是“后端语言”是一种口语化说法，严格讲 Node 是 JS 的运行时环境，语言仍然是 JavaScript。

三、包（package）

把多个模块组合为一个完整的功能，就是一个包。

包结构

  • bin：二进制的可执行文件，一般只有工具包才有
  • lib：js 文件
  • doc：文档
  • test：测试代码
  • package.json：包的描述文件，json 格式
    • name：包名
    • version：版本
    • dependencies：依赖
    • main：包的主要文件
    • bin：可执行文件

npm 会在安装完 Node 以后自动安装；通过 npm 下载的包都放在 node_modules 文件夹中，引入时直接写包名即可。

六、模块化

ES5 中没有原生支持模块化，只能通过 script 标签引入 js 文件来模拟；Node 为了管理模块，引入了 CommonJS 规范。

模块的定义

  • 在 Node 中，一个 js 文件就是一个模块
  • 默认情况下，js 文件里编写的内容都运行在一个独立的函数中，外部模块无法访问

  • Node 通过模块的标识来寻找模块
