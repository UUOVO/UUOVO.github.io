CSS 渐变有三种：线性的 linear-gradient、径向的 radial-gradient、圆锥的 conic-gradient，三种都有对应的 repeating- 版本用来铺满容器。核心只有两件事：给一个方向（或位置），再给若干“颜色 + 起止位置”；颜色带区间就出硬边条纹，颜色不带区间就是平滑过渡。这篇把六种写法、参数含义和一个充电环实例整理在一起。

踩坑与注意点

  • 渐变是图片，必须写在 background-image 或 background 上，写在 background-color 上无效。
  • 重复渐变的关键是给出长度或百分比范围；只写颜色不会重复，这是最常见的“没效果”原因。
  • 渐变关键字（如 to right）在小程序中无效，需要改用角度。
  • 上面实例中的 if (center > 100) clearInterval(timer) 比较的是 DOM 元素而不是计数变量，按原意应当是 cnt > 100；此处保留原文，仅作提醒。
  • 同一实例中 cnt 没有上限约束，持续累加会让百分比超过 100%，实际使用时建议先判断再修改样式。
