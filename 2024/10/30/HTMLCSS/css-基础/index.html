网页由结构（HTML）、表现（CSS）、行为（JavaScript）三部分组成，CSS 负责表现。写 CSS 之前要解决四件事：样式写在哪里、选择器命中谁、样式为什么被覆盖、数值用什么单位。这篇按这个顺序把基础概念串起来，最后附上 CSS3 常用属性和预处理器的区别，可以当速查表用。

背景：网页的三个部分

  • 结构（HTML）
  • 表现（CSS）—— 用来设置网页中元素的样式
  • 行为（JavaScript）

第一步：选择 CSS 的书写位置

CSS 有三种写法，区别在于作用范围能否复用。

第一种方式：内联样式（行内样式）

在标签内部通过 style 属性来设置元素的样式。

  • 缺点：样式只能对一个标签生效
  • 注意：开发时绝对不要使用内联样式

第二种方式：内部样式表

将样式编写到 head 中的 style 标签里，通过 CSS 的选择器选中元素并为其设置各种样式。

  • 优点：
    • 可以同时为多个标签设置样式，并且修改时只需要修改一处即可全部应用
    • 方便对样式进行复用
  • 缺点：只能对一个网页起作用，不能跨页面进行复用

第三种方式：外部样式表（最佳实践）

将 CSS 样式编写到一个外部的 CSS 文件中，然后通过 link 标签引入。

  • 优点：
    • 外部样式表通过 link 标签引入，使样式可以在不同页面之间进行复用
    • 可以使用到浏览器的缓存机制，从而加快网页的加载速度，提高用户的体验

第二步：理清元素之间的关系

  • 父元素：直接包含子元素的元素叫做父元素。
  • 子元素：直接被父元素包含的元素是子元素。
  • 祖先元素：直接或间接包含后代元素的元素叫做祖先元素；一个元素的父元素也是它的祖先元素。
  • 后代元素：直接或间接被祖先元素包含的元素叫做后代元素；子元素也是后代元素。
  • 兄弟元素：拥有相同父元素的元素是兄弟元素。

第三步：理解继承与样式冲突

样式的继承

为一个元素设置的样式同时也会应用到它的后代元素上，继承发生在祖先与后代之间。

继承的设计是为了方便开发：利用继承可以把通用样式统一设置到共同的祖先元素上，只需设置一次即可让所有元素都具有该样式。

注意：并不是所有的样式都会被继承，比如背景相关、布局相关等样式都不会被继承。

样式的冲突

当我们通过不同的选择器选中相同的元素，并且为相同的样式设置不同的值时，就发生了样式的冲突。发生冲突时应用哪个样式，由选择器的权重（优先级）决定。

第四步：掌握长度单位、角度单位与颜色单位

长度单位

在 CSS 中使用的都是相对单位。

  • px（Pixels 像素）
    • 屏幕（显示器）实际上是由一个一个的小点点构成的
    • 不同屏幕的像素大小是不同的，像素越小的屏幕显示的效果越清晰
    • 所以同样的 200px 在不同的设备下显示效果不一样
    • web 开发中的主流，在分辨率的宽高中占 npx/分辨率宽
  • **%**（百分比）
    • 可以将属性值设置为相对于其父元素的百分比
    • 设置百分比可以使子元素跟随父元素的改变而改变
    • 对于 font-size、line-height 等属性是基于其父元素的 font-size
    • 对于 text-indent、margin、padding、width 等属性则是基于父元素的宽度
  • em（元素的字体高度）
    • em 是相对于元素的字体大小来计算的
    • 『基于当前元素/父元素的 font-size』：当前元素 12px 的话，font-size：12/nem
    • 1em = 1font-size = 16px
    • em 会根据字体大小的改变而改变
    • 具有级联关系
  • rem：根元素（html）的 font-size，CSS3 新增
    • rem 是相对于根元素的字体大小来计算
    • 无级联
    • IE8 及以下、Safari 4、iOS 3.2 等不支持 rem
  • ex：x-height，字母 x 的高度
  • ch：字符 0 的宽度，CSS3 新增
  • vw：视窗宽度（viewport width），CSS3 新增
    • 1vw = 视窗宽度的 1%
  • vh：视窗高度（viewport height），CSS3 新增
    • 1vh = 视窗高度的 1%
  • vmin：以较小者为准，1vmin，CSS3 新增
  • vmax：以较大者为准，1vmax，CSS3 新增

角度单位

  • deg（度）：一个圆 360°
  • grad（梯度）：一个圆共 400 梯度
  • rad（弧度）：一个圆共 2Π 弧度
  • turn（转、圈）：一个圆共一圈

第五步：了解 CSS 预处理器的区别

概念

CSS 预处理器是一种语言，用来为 CSS 增加一些编程的特性，无需考虑浏览器兼容问题。例如可以在 CSS 中使用变量、简单的程序逻辑、函数等在编程语言中的基本技巧，让 CSS 更加简洁、适应性更强、代码更直观。

区别

  • 扩展名：Sass 以 .sass 为扩展名，Less 以 .less 为扩展名，Stylus 以 .styl 为扩展名。
  • 变量写法：
    • Sass 变量必须以 $ 开头，变量和值之间使用冒号隔开，和 CSS 属性一样
    • Less 变量以 @ 开头，其余和 Sass 一样
    • Stylus 对变量没有设定，可以用 $ 开头或任意字符，变量之间可以用冒号或空格隔开，但不能用 @ 开头
  • 三种预处理器都有嵌套、运算符、颜色函数、导入、继承、混入；Stylus 还有一些高级特性，例如循环、判断等。

第六步：CSS3 常用属性速查

box-shadow（设置元素阴影）

  • x-offset：水平偏移量
  • y-offset：垂直偏移量
  • blur-radius：可选，模糊半径，默认值为 0
  • spread-radius：可选，扩散半径，默认值为 0
  • color：可选，阴影颜色，默认继承元素的 color 属性
  • inset：可选，是否内部阴影，默认为外部阴影

text-shadow（设置文本阴影）

  • x-offset：水平偏移量
  • y-offset：垂直偏移量
  • blur-radius：可选，模糊半径，默认值为 0
  • color：可选，阴影颜色，默认继承元素的 color 属性

border-image（设置边框图片）

  • border-image-source: url()：图片路径
  • border-image-slice：上右下左偏移量
  • border-image-width：图片宽度
  • border-image-outset：图边框图像超过边框盒的量，默认值为 0
  • border-image-repeat：stretch（拉伸）| repeat（重复）| round（缩放自适应），用于设置图片重复方式

border-radius（圆角半径）

box-reflect（反射）
