第 1 步：区分不同版本的 Vue

vue.js 与 vue.runtime.xxx.js 的区别：

  • vue.js 是完整版的 Vue，包含核心功能 + 模板解析器。
  • vue.runtime.xxx.js 是运行版的 Vue，只包含核心功能，没有模板解析器。

因为 vue.runtime.xxx.js 没有模板解析器，所以不能使用 template 配置项，需要使用 render 函数接收到的 createElement 函数去指定具体内容。

第 8 步：组件化编码流程

  1. 拆分静态组件：组件要按照功能点拆分，命名不要与 html 元素冲突。

第 10 步：nextTick

调用形式：

  • 作用：在下一次 DOM 更新结束后执行其指定的回调。
  • 使用场景：当改变数据后，要基于更新后的新 DOM 进行某些操作时，要在 nextTick 所指定的回调函数中执行。
  • 不用定时器的原因：setInterval 会无限循环。
  • 原理：nextTick 主要使用了宏任务和微任务。根据执行环境分别尝试采用 Promise、MutationObserver、setImmediate，都不行则用 setTimeout 定义一个异步方法；多次调用时，nextTick 会将方法存入队列中，通过这个异步方法清空当前队列。
  • 实现：『Vue 在更新 DOM 时是异步执行的。』只要侦听到数据变化，Vue 将开启 1 个队列，并缓冲在同一事件循环中发生的所有数据变更。如果一个 watcher 被『多次』触发，只会被推入到队列中『一次』，避免不必要的计算和 DOM 操作。nextTick 方法会在队列中加入一个回调函数，确保该函数在前面的 DOM 操作完成后才调用。

第 11 步：Vue 封装的过渡与动画

作用：在插入、更新或移除 DOM 元素时，在合适的时候给元素添加样式类名。

写法一：使用 transition 标签包裹要过渡的元素，并配置 name 属性。

  • 如果给 transition 标签添加 appear 属性，代表一出场就要有动画。
  • 在 style 标签中写好动画样式，按以下规则命名：
    • 元素进入的样式：
      1. name-enter：进入的起点
      2. name-enter-active：进入过程中
      3. name-enter-to：进入的终点
    • 元素离开的样式：
      1. name-leave：离开的起点
      2. name-leave-active：离开过程中
      3. name-leave-to：离开的终点
  • 若有多个元素需要过渡，则需要使用 transition-group 标签替换 transition 标签，且每个元素都要指定 key 值。

写法二：也可以使用外部样式表 + 标签来展示。

  • 页面标签同上。
  • 引入外部样式表。
  • 将样式赋给标签上对应的样式（与上面的命名规则类似，不要前面的 name-，在后面加 -class）。

常见的动画样式：animation + @keyframes、transition、transform。

第 12 步：解决跨域的方式

页面使用 axios 请求接口时，会存在浏览器跨域的问题，这是因为同源策略。

  • 同源策略/SOP（Same origin policy）：一种约定，由 Netscape 公司 1995 年引入浏览器，它是浏览器最核心也最基本的安全功能，如果缺少了，浏览器很容易受到 XSS、CSRF 等攻击。
  • 所谓同源，指的是“协议 + 域名 + 端口”三者相同，只要有一个不同就会导致跨域问题。

解决方案：

  1. cors，主要靠后端。
  2. jsonp，前后端配合。
  3. 代理服务器：
    • nginx
    • vue

  • 本地的端口一般默认是 8080，所以配置 proxy 写的是另一个服务器的端口号。
  • 都是在 vue.config.js 文件中添加配置。

接口配置属性的解析：

第 14 步：额外补充的知识

  • obj.hasOwnProperty('属性名')：判断对象身上是否存在某一元素。

踩坑与注意点

  • props 是只读的，不要在子组件里直接改；需要“可写”时用 v-bind 把 props 值同步到 data，或改由父组件更新。
  • props 传的是对象时，子组件改对象内部属性不会报警告，但会污染父组件数据，仍不推荐。
  • scoped 只作用于当前组件的模板，不影响子组件根元素以外的内容。
  • nextTick 要等 DOM 更新完再取元素，直接紧跟赋值语句之后读取会拿到旧 DOM。
  • 代理方法一无法配置多个代理，也不能灵活控制；需要多目标时用方法二并记得加路径前缀。
  • pathRewrite 只是把前缀从发给后端的路径里去掉，前端请求时仍然要带着这个前缀。
  • 过渡动画的类名必须以 transition 的 name 为前缀，写成外部样式表时要注意 -class 的对应关系。
