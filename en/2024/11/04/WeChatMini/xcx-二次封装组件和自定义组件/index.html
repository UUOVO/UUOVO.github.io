这篇解决什么问题：把小程序里「二次封装基础组件」和「新建自定义组件」的流程跑通。核心是两件事：用 npm 引入组件库并构建；在封装层把 props 透传成 properties、把 slot 透传出去，再用 usingComponents 注册组件。

一、安装 npm

  1. 进入小程序根目录，运行 cmd，输入下面的命令初始化：
  1. 输入命令之后一直点回车。
  2. 输入要安装的组件命令（原文未给出具体命令，按所用组件库的文档执行）。
  3. 执行完命令之后，再点击微信开发者工具中的「工具 - 构建 npm」，就成功了。

二、使用 Vant Weapp 组件库

  1. 进入 Vant Weapp 官网。
  2. 按照官网的介绍选择对应的工具安装，使用 npm 时走前四步就行。

三、二次封装组件

整体思路：在基础组件外再包一层自己的组件，把需要暴露的 props 声明到 properties，把原组件的标签、方法和插槽写进封装组件的 WXML。

第 1 步：建立目录

  1. 新建一个 components 文件夹。
  2. 在 components 文件夹下再新建一个 base 文件夹，用来存放基础组件。
  3. 如果要存放业务组件就用 business；看 components 文件夹的位置决定组件是全局还是局部。
  4. 在 base 中新建文件夹 a 用来封装组件（原生小程序里面有 4-5 个文件，后缀分别为 json、js、wxml、wxss、ts）。

注意点

  • 封装组件的命名建议与文件名一致，并采用 aa-bbb 的形式。
  • 只声明需要用到的 properties，否则封装层会多出一批用不到的属性。
  • 默认 styleIsolation 为隔离状态，页面要覆盖组件样式时才需要改成 shared。
