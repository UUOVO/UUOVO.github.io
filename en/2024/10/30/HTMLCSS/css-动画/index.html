CSS 里做动效有三套东西：transition 需要外力推动、只做一次性切换；animation 可以自动播放、能循环和往返；transform 本身不产生动画，只改变元素的形状或位置，但它是前两者最常操作的对象。搞清这三者的触发条件，才知道该选哪个。这篇按过渡、动画、变形三部分整理完整属性清单和写法。

背景：先分清谁负责什么

  • 过渡（transition）：通过过渡可以指定一个属性发生变化时的切换方式，必须有外力推动，效果是一次性的，只能从边界开始或结束。
  • 动画（animation）：过渡需要在某个属性发生变化时才会触发，而动画可以自动触发动态效果。
  • 变形（transform）：通过 CSS 来改变元素的形状或位置，变形不会影响到页面的布局。

过渡是“值变了才动”，所以先要有状态变化（例如 :hover），再声明过渡规则。

简写语法

动画的简写按下面的顺序书写：

属性

  • animation-name：要对当前元素生效的关键帧的名字
  • animation-duration：动画的执行时间
  • animation-delay：动画延时多久再执行
  • animation-timing-function：指定动画以什么方式执行
  • animation-iteration-count：动画循环的次数
    • 可选值：number 次数 | infinite 无限执行
  • animation-direction：指定动画运行的方向
    • 可选值：
      • normal：默认值，从 from 向 to 运行，每次都是这样
      • reverse：从 to 向 from 运行，每次都是这样
      • alternate：从 from 向 to 运行，重复执行动画时反向执行
      • alternate-reverse：从 to 向 from 运行，重复执行动画时反向执行
  • animation-play-state：设置动画的执行状态
    • 可选值：
      • running：默认值，动画执行
      • paused：动画暂停
  • animation-fill-mode：动画的填充模式
    • 可选值：
      • none：默认值，动画执行完毕元素回到原来位置
      • forwards：动画执行完毕元素会停止在动画结束的位置
      • backwards：动画延时等待时，元素就会处于开始位置
      • both：结合了 forwards 和 backwards

三、变形（transform）

变形只改变元素的样子，不参与页面布局计算，因此不会引起周围元素重排。

平移（translate）

  • translateX(x)：沿着 x 轴方向平移
  • translateY(y)：沿着 y 轴方向平移
  • translateZ(z)：沿着 z 轴方向平移
  • translate(x,y)：定义 2D 转换
  • translate3d(x,y,z)：定义 3D 转换
  • 平移元素时，百分比是相对于自身计算的
  • z 轴平移用来调整元素在 z 轴的位置，正常情况就是调整元素和人眼之间的距离，距离越大，元素离人越近
  • z 轴平移属于立体效果（近大远小），默认情况下网页是不支持透视的，如果需要看见效果，必须要设置网页的视距

旋转（rotate）

  • rotateX(angle)：使元素沿着 x 轴的 2D 旋转指定的角度
  • rotateY(angle)：使元素沿着 y 轴的 2D 旋转指定的角度
  • rotateZ(angle)：使元素沿着 z 轴的 3D 旋转指定的角度
  • rotate(angle)：定义 2D 旋转，在参数中规定角度
  • rotate3d(x,y,z,angle)：定义 3D 旋转

缩放（scale）

  • scaleX(x)：水平方向缩放
  • scaleY(y)：垂直方向缩放
  • scaleZ(z)：通过设置 Z 轴的值来定义 3D 缩放转换
  • scale(x,y)：定义 2D 缩放转换
  • scale3d(x,y,z)：定义 3D 缩放转换

倾斜（skew）

  • skew(x-angle,y-angle)：定义沿着 X 和 Y 轴的 2D 倾斜转换
  • skewX(angle)：定义沿着 X 轴的 2D 倾斜转换
  • skewY(angle)：定义沿着 Y 轴的 2D 倾斜转换

变换矩阵（matrix）

  • matrix(n,n,n,n,n,n)：定义 2D 转换，使用六个值的矩阵
  • matrix3d(n,n,n,n,n,n,n,n,n,n,n,n,n,n,n,n)：定义 3D 转换，使用 16 个值的 4x4 矩阵

transform-origin：变换的原点

它用来更换元素变换的基准点，语法如下：

  • x-axis：定义视图被置于 X 轴的何处，可取 left、right、center、length、%
  • y-axis：定义视图被置于 Y 轴的何处，可取 top、center、bottom、length、%
  • z-axis：定义视图被置于 Z 轴的何处，取 length

transform-style：让子元素保留 3D 转换

语法中的两个取值含义如下：

  • flat：表示所有子元素在 2D 平面呈现
  • preserve-3d：表示所有子元素在 3D 空间中呈现

perspective：视距

语法如下：

  • number：元素距离视图的距离，单位像素
  • none：默认值，不设置透视
  • 该属性『设置从何处查看一个元素的角度』
  • 只影响 3D 转换元素

踩坑与注意点

  • 过渡必须从一个有效数值过渡到另一个有效数值，height: auto 这类无法参与计算的值不会产生过渡。
  • transition 是一次性的，只能从边界开始或结束；需要自动播放、循环或往返，用 animation。
  • 关键帧的百分比写法从 0% 到 100%，from/to 写法与之等价，不要混用在同一个关键帧里。
  • animation-fill-mode 决定动画结束后元素停在哪，默认 none 会回到原来的位置。
  • 3D 效果要看到透视，必须设置视距，并且父元素配合 transform-style: preserve-3d（可参考《CSS-3D变换中的改变层级的属性》）。
