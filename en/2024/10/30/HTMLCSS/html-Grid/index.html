这篇按「先划格子，再放元素，最后调对齐」的顺序整理 Grid：grid-template-* 负责划分行列，gap 控制间距，grid-row / grid-column 与 grid-area 负责定位，justify-* / align-* 负责对齐。结论：Grid 是二维布局，先确定轨道（行和列），再把元素放进指定的网格线或区域，比用 float 拼布局更直观。

背景

  • 本文只写关键代码，完整示例布局可对照 html/GTA5 封面.html。
  • 示例默认外层容器为 .outer，子元素为 .div1 等。

一、划分行列

1. grid-template-columns 划分列数

划几列就写几个值，每个值代表该列的宽度。

2. grid-template-rows 划分行数

划几行就写几个值，每个值代表该行的高度。

3. repeat() 重复设置

  • 参数一：重复的数量。
  • 参数二：重复的值，可以有多个，用空格连接。

4. 自动填充 auto-fit

根据容器尺寸自动设置元素尺寸。

5. 比例划分

  • 使用 fr 单位设置元素在空间中所占的比例。
  • 可以结合 repeat 重复定义。

6. 自动空间 auto

在值中使用 auto，会获取剩余空间。

7. 组合定义

grid-template 可以同时定义行、列，或直接定义区域。

用区域方式定义时，点号代表占位符：

8. 最大最小值 minmax()

取值范围在最小到最大之间，左边最小，右边最大。

二、间距定义

  1. 行间距：row-gap。
  2. 列间距：column-gap。
  3. 组合定义：gap。
    • 一个值：行列统一。
    • 两个值：第一个是行，第二个是列。

三、元素定位

  1. grid-row-start：行开始网格线。
  2. grid-row-end：行结束网格线。
  3. grid-column-start：列开始网格线。
  4. grid-column-end：列结束网格线。

以上属性的共有取值：

  • Line：网格线。
  • span 数值：网格包含的网格数量。
  • span 区域名称：网格包含到指定的区域名称。
  • auto：自动设置，默认占一个网格的宽高。

5. 根据网格线定位

通过设置具体的第几条网格线来确定区域位置，数值可以是正数或负数。

6. 根据偏移量 span 定位

使用 span 可以设置包含网格的数量，或包含到的区域名称。

7. 根据网格命名定位

见下文「网格命名」小节。

8. 简写模式

  • 使用 grid-row 设置行的开始与结束网格线。
  • 使用 grid-column 设置列的开始与结束网格线。

9. 更简洁的组合写法

grid-area 依次接收行开始、列开始、行结束、列结束。

10. 实现类似 Bootstrap 的布局

结合 repeat、fr 与 gap，可以写出类似 Bootstrap 栅格的多列布局。

四、网格命名

独立命名

先给网格线单独命名，再在定义行列宽时把线名写进去。

自动命名

用 repeat 重复生成同名网格线，再用「线名 + 序号」定位。

五、区域换位

1. 编号定位

先定义行列，再用编号把元素放到指定区域。

2. 命名定位

先给网格线命名，再用线名定位。

六、区域声明

以移动端页面结构为例。

1. 区域布局

每个子元素添加对应的 grid-area: 子元素命名;，再在父元素中声明区域。

其中 aaa、bbb、ccc、ddd、eee 代表子元素的命名，命名放在哪里，就代表子元素占用哪个位置。

2. 简写形式

每个子元素添加对应的 grid-area: 栅格名称;，再在父元素中用 grid-template 简写。

3. 区域命名（系统自动命名）

只要子元素命名了网格线所在的区域，栅格名称会自动生成。

4. 区域占位

使用一个或多个 . 占位，一个 . 代表一个位置。

七、网格流动

1. grid-auto-flow 改变单元格排列方式

  • column：按列排序。
  • row：按行排序。
  • dense：让后面的元素回填前面空余的栅格。

2. 在父元素使用

grid-auto-flow 写在网格容器上。

3. 强制填充

当元素在栅格中放不下时，会发生换行并产生留白；使用 grid-auto-flow: row dense; 可以执行填充空白区域的操作。

八、对齐管理

  • justify-content：所有栅格在容器中的水平对齐方式，容器有额外空间时生效。
  • align-content：所有栅格在容器中的垂直对齐方式，容器有额外空间时生效。
  • align-items：栅格内所有元素的垂直排列方式。
  • justify-items：栅格内所有元素的横向排列方式。
  • align-self：元素在栅格中的垂直对齐方式。
  • justify-self：元素在栅格中的水平对齐方式。

1. 网格对齐

justify-content 的取值：

值 说明
start 容器左边
end 容器右边
center 容器中间
stretch 撑满容器
space-between 第一个栅格靠左边，最后一个栅格靠右边，余下元素平均分配空间
space-around 每个元素两侧的间隔相等，栅格之间的间隔比栅格与容器边距的间隔大一倍
space-evenly 栅格间距离完全平均分配

align-content 的取值：

值 说明
start 容器顶边
end 容器底边
center 容器垂直中间
stretch 撑满容器
space-between 第一个栅格靠左边，最后一个栅格靠右边，余下元素平均分配空间
space-around 每个元素两侧的间隔相等，栅格之间的间隔比栅格与容器边距的间隔大一倍
space-evenly 栅格间距离完全平均分配

2. 元素对齐

justify-items 控制元素的水平对齐方式：

值 说明
start 元素对齐栅格的左边
end 元素对齐栅格的右边
center 元素对齐栅格的中间
stretch 水平撑满栅格

align-items 控制元素的垂直对齐方式：

值 说明
start 元素对齐栅格的顶边
end 元素对齐栅格的底边
center 元素对齐栅格的垂直中间
stretch 垂直撑满栅格

3. 简写

用 place-* 简写可以一次设置两个方向的对齐。

九、自动排列

  • grid-auto-rows：控制自动增加的栅格行的尺寸，grid-auto-flow: row 为默认。
  • grid-auto-columns：控制自动增加的栅格列的尺寸，grid-auto-flow: column 时使用。

注意点

  • repeat(auto-fill, [c] 100px) 会重复生成同名网格线，定位时要用 c 2 这种「线名 + 序号」的写法。
  • auto-fit 与 auto-fill 不同：auto-fit 会合并空轨道，auto-fill 会保留空轨道。
  • justify-* 管行内轴（默认水平），align-* 管块轴（默认垂直）；当 grid-auto-flow: column 时两者方向互换。
