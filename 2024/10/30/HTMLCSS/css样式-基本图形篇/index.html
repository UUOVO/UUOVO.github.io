这篇解决两类「临时搜一段代码」的问题：一是在微信小程序里实现带连接线的垂直/横向步骤条；二是只用 CSS 画出箭头、三角形、六角形、五角星和爱心。步骤条的难点不在布局，而在连接线与伪元素层级；图形篇的关键则是把正方形用 border 切成三角形。下面按「步骤条 → checkbox → 图标动画 → 几何图形」的顺序给出可直接复用的代码。

适用场景与前提

  • 步骤条示例基于微信小程序，列表数据是动态的，所以模板里用 wx:for 渲染。
  • 样式写在 wxss 中；方案二用到 & 嵌套和 // 注释，属于 SCSS 语法，需要项目已支持 SCSS。
  • 箭头示例来自 React + 微信小程序，标签写作 <View />，换到原生小程序时改成 <view> 即可。

一、自定义组件：步骤条

垂直布局

难点：图标中间的连接线与层级。做法是用伪元素画线，再用绝对定位把它放到图标之间。

实现步骤：

  1. 先完成基础布局，让每一项横向排列。
  2. 观察 icon 所在位置，给 icon 外面加一层容器，这层容器专门用来定位。
  3. 给 icon 加样式：固定宽高、overflow: visible，再添加伪类，display: inline-block 并给宽高。
  4. 此时页面上能看到这条线，再调整居中。
  5. 最后通过判断当前项是不是最后一个元素来决定是否显示这条线，或用 :not(:last-child)::after 只给非最后一项加中间线。

方案一：模板 + WXSS

模板用 wx:if 区分最后一项：非最后一项的图标带 plan-box-step-image 类，供伪元素画线；最后一项使用固定尺寸。

样式让外层横向排列、图标容器相对定位，并用 ::after 画出 4rpx 宽的浅灰竖线。

方案二：模板 + SCSS

模板结构与方案一相近，但把所有项放进 .step-1，连接线交给 .step-1:not(:last-child)::after。

样式用 flex 排列图标，并给非最后一项补一条竖线；缺点是线到 y 轴的距离要手动调。

横向布局

难点：伪类层级太高会遮住子元素。

实现步骤：

  1. 把文本和图标（或中间圆点）放进同一个容器，然后对这层公共容器操作。
  2. 用 :first-child 和 :last-child 对齐容器前后的元素。
  3. 公共容器设置 position: relative。
  4. 给图标添加 ::after 伪类，绝对定位，宽度 100%。

模板把每一项包成 .box，样式在 .box:not(:last-child)::after 上画虚线。

二、checkbox 样式修改

场景：微信小程序原生 checkbox 自带勾选框，想换成自定义样式时，需要覆盖 wx-checkbox-input 相关类。

下面三段分别去掉未选中框、选中框和选中图标的默认外观。

三、字体图标动画

给需要动画的字体图标补上动画属性，再用 @keyframes 描述关键帧。

  1. 使用 @keyframes 添加动画效果。
  2. 字体图标需要缩放时，用 transform: scale() 调整大小。
  3. 字体图标如果无法用弹性布局居中，关键在 display: inline-block；也可以考虑把 display 改为 block。

四、几何图形

所有图形都围绕同一套思路：width/height 设为 0 或固定值，用 border 的透明边切出形状，再用伪元素与定位组合。

四分之一圆

  1. 需要给定宽高。
  2. 用 border-top-left-radius: 250rpx; 实现四分之一圆，可调整弧线位置。
  3. 位置通过定位实现。

箭头

以 React + 微信小程序的案例为模板。

  1. 准备一个空容器。
  2. 给容器一个宽高，形成一条线。
  3. 给容器添加 ::before 伪元素。
  4. 伪元素宽高为 0，border 按线条给出合适的宽高，然后整体设为透明。
  5. 想要哪个方向的箭头，就给对应方向的 border 添加宽高和颜色。

模板只有一个空容器。

样式先画一条横线，再用伪元素的 border 拼出箭头。

等腰三角形

  • 宽高为 0。
  • 正方形的哪条边占满，border 的哪边就填充颜色，并且它对应的左右两边设为透明。
  • 一共只需要设置三边。
  • 例如：正方形左边占满，则上下两边透明、左边有颜色，border 宽度保持一致。

直角三角形

  • 宽高为 0。
  • 观察想要的直角三角形在正方形中的位置：垂直方向填充颜色，水平方向相反的一侧设为透明。
  • 一共只需要设置两边。
  • 例如：直角三角形位于正方形左下，则下边填充颜色、右边透明，border 宽度一致。

梯形

  • 高为 0，宽固定。
  • border 底边与宽度一样并填充颜色，左右长度为宽的一半并设为透明。

平行四边形

  • 矩形 + 倾斜。
  • 用 transform: skew(20deg) 倾斜。

六角形

  • 两个三角形叠加。
  • 用伪元素 + 定位实现。

五角星

  • 三个同样大小的三角形旋转可得，或三个不同大小的三角形叠加。
  • 用伪元素 + 定位 + transform: rotate() 实现。

爱心

  • 一个三角形 + 两个圆。
  • 用伪元素 + 定位实现。

注意点

  • 方案二需要在样式里手动调整 translate(-30rpx, 60rpx)，这个值与图标尺寸绑定，换尺寸要同步修改。
  • 横向布局的线加在 .box 上而不是图标上，只有配合 transform-style: preserve-3d 和 translateZ(-1px) 才不会被子元素遮住。
  • 字体图标无法用 flex 居中时，先检查是不是 inline-block 造成的；可以改为 block 再居中。
