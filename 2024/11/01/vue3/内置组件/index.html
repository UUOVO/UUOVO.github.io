结论先行：Vue3 有三个常用的内置组件。Transition 负责单个元素或组件进入、离开 DOM 时的动画，TransitionGroup 负责 v-for 列表项的插入、移动和移除动画，KeepAlive 负责缓存被切走的组件实例，Teleport 负责把内容渲染到应用外部的指定容器。这篇按“什么时候触发 → 用哪些 class → 怎么命名和定制 → 生命周期与属性”的顺序，给出四者的最小可用写法。

背景：内置组件解决什么场景问题

普通组件只能控制内容和结构，而“动画、缓存、传送”这三类能力需要框架介入 DOM 操作：

  • 动画：需要知道元素是什么时候插入、什么时候移除的，才能在正确的时机加 class
  • 缓存：需要在组件被切走时保留实例和状态，而不是销毁重建
  • 传送：需要把模态框、通知这类内容渲染到 body 或其他容器，但逻辑上仍属于当前组件

步骤 1：用 Transition 做进入/离开动画

Transition 在一个元素或组件进入和离开 DOM 时应用动画。

触发条件

  • 由 v-if 所触发的切换
  • 由 v-show 所触发的切换
  • 由特殊元素 <component> 标签切换的动态组件

基于 CSS 的过渡效果

Vue 会在过渡的不同阶段切换下面这些 class：

  • v-enter-from：进入动画的起始状态
  • v-enter-active：进入动画的生效状态
  • v-enter-to：进入动画的结束状态
  • v-leave-from：离开动画的起始状态
  • v-leave-active：离开动画的生效状态
  • v-leave-to：离开动画的结束状态

步骤 2：用 TransitionGroup 给列表加动画

TransitionGroup 在一个 v-for 列表中的元素或组件被插入、移动或移除时应用动画。

  • tag?：指明渲染的片段容器标签

步骤 3：用 KeepAlive 缓存组件实例

KeepAlive 用于『在多个组件间动态切换时缓存被移除的组件实例』。

下面的对比展示了有无缓存的区别：不加 KeepAlive 时切换会重置状态，加上后切换会保留切换前的状态。

include / exclude / max

  • include：只缓存名称匹配的组件
  • exclude：不缓存名称匹配的组件
  • max：最大缓存实例数

三者都以组件的 name 参数匹配。

生命周期钩子

当一个组件在 KeepAlive 标签中被切换时，它的 activated 和 deactivated 生命周期钩子将被调用，用来替代 mounted 和 unmounted。

步骤 4：用 Teleport 把内容传送到别处

Teleport 用于这样的场景：组件模板的一部分在逻辑上从属于该组件，但从整个应用视图的角度来看，它在 DOM 中应该被渲染到整个 Vue 应用外部的其他地方，例如全屏的模态框。

多个 Teleport 挂载到同一目标

多个 <Teleport> 组件可以将其内容挂载在同一个目标元素上。顺序是从上往下，后挂载的将排在目标元素下更后面的位置上。

属性 to

to 指定渲染到哪个元素或容器。

属性 disabled

disabled 用于禁用传送，禁用后不渲染到外层容器或元素。

注意点

  1. Transition 只有在元素真正插入或移除时才会触发；用 v-show 或 mode 控制时要确认 DOM 节点确实发生了切换。
  2. 同时写 transition 和 animation 时，务必用 type 指定以哪个时长为准，否则容易出现过早移除 class 的问题。
  3. 深层级过渡需要显式 :duration，否则子元素的动画时长不会被计入。
  4. KeepAlive 的 include / exclude 传数组或正则时要用 v-bind（:include），直接写字符串则按逗号分隔的名字匹配。
  5. 被 KeepAlive 缓存的组件不会重复执行 created / mounted，需要感知激活和停用时改用 activated / deactivated。
  6. Teleport 的 to 目标元素必须已经存在于 DOM 中，否则会报找不到目标。
  7. 列表动画使用 TransitionGroup 时，列表项需要稳定的 key，否则移动动画无法正确识别节点。
