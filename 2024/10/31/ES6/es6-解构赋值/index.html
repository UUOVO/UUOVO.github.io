解构赋值就是”从数组或对象中提取值，对变量进行赋值”。记住三条规则就能覆盖大部分场景：数组按位置一一对应、对象按属性名对应（与顺序无关）、默认值只在取到的值严格等于 undefined 时生效。下面按”数组 → 默认值 → 对象 → 嵌套 → 特殊类型 → 函数参数”的顺序整理，每个示例保留原笔记的注释和输出。

背景：为什么需要解构

取嵌套数据时，传统写法要一层层点出来，变量一多就重复；交换变量、给函数返回的多个值命名也不方便。解构赋值把”取值”和”声明”合成一条语句，可读性和简洁度都更好，代价是模式与右侧结构必须对应，否则容易得到 undefined 或直接报错。

1. 数组解构：按位置一一对应

一句话：左边是数组模式时，按位置取值，嵌套结构也要对应上。

一句话：如果想取后面的值、前面不赋值，用 , 占位，跳过几个位置就写几个逗号。

一句话：不完全解构时，等号左边的模式只匹配右侧数组的一部分，剩下的被忽略。

2. 默认值：只在 undefined 时生效

一句话：数组/对象成员严格等于 undefined，默认值才会生效；成员是 null，默认值就不会生效。

注意：这三组示例在原笔记里都用了 let [x, y = 'b']，连续执行会因重复声明报错，这里把后面两组的变量名改成 x2、y2、x3，取值和结论不变。若要验证 null 的情况，let [n = 1] = [null] 得到的 n 是 null。

3. 对象解构：按属性名对应

一句话：左边是对象模式时，按属性名取值，与书写顺序无关；取不到的属性得到 undefined。

4. 嵌套解构

一句话：对象里套数组、数组里套对象都可以，模式形状要和右侧结构对应。

注意：p: [x, { y }] 是在取出 p 之后继续对它解构，同一个模式里既声明了 p，也声明了 x 和 y，三个变量都存在。

5. 注意点

一句话：如果要将一个已经声明的变量用于解构赋值，整条语句必须用圆括号包起来，否则开头的大括号会被当成代码块。

一句话：解构赋值允许等号左边的模式之中不放置任何变量名，此时只做取值动作。

一句话：数组本质是特殊的对象，因此可以对数组进行对象属性的解构，用索引作属性名。

一句话：不要使用圆括号——除了上面”整条赋值语句加括号”这种必需情况，模式内部不要再加圆括号。

6. 字符串、数值与布尔值：先转成对象

一句话：字符串会被转换成一个类数组的对象，所以能解构出 length 这类属性。

一句话：数值、布尔值等原始值也会先转成包装对象，所以能解构出原型上的方法。

注意：另外 undefined 和 null 无法转为对象，let { toString: s } = null 会抛 TypeError。

7. 函数参数解构

一句话：函数参数位置也能直接用默认值参与解构，数组元素是 undefined 时会被参数默认值替代。

注意：这里生效的是”参数默认值”而非解构默认值——map 会把数组元素逐个作为实参传入，undefined 触发了 x = 'yes' 的默认值。

踩坑与注意点

  1. 数组解构按位置取值，位置错了不会报错，只会得到 undefined。
  2. 默认值只对 undefined 生效，null、0、''、false 都会覆盖默认值。
  3. 已声明变量做对象解构必须写成 ({x} = obj)，漏掉括号会报 SyntaxError。
  4. 对象解构的 { foo: baz } 中，foo 是要取的属性名，baz 才是新变量。
  5. 对 null / undefined 做解构会抛 TypeError，取深层数据前要先判空。
