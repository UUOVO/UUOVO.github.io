结论先行

这篇汇总三类工程配置：tsconfig.json 的常用编译选项与路径别名、webpack 的概念与核心组成、以及 Sass 的 at-rules（@use、@mixin、@extend）。核心结论是：TS 别名要同时配 baseUrl 和带 /* 的 paths，否则编辑器会飘红；webpack 记住「入口、输出、loader、插件、模式、浏览器兼容、环境」七个核心；Sass 的颜色、混入、继承都可以用内置模块函数完成。

背景

项目里常被问到的配置问题是「TS 路径别名为什么不生效」「tsconfig 的 include/exclude 怎么排」「webpack 到底有哪些核心配置」「Sass 的 @use 和 @mixin 怎么用」。下面按配置文件逐一整理。

步骤一：配置 tsconfig.json

compileOnSave

compileOnSave: true 让 IDE 在保存文件的时候根据 tsconfig.json 重新生成文件。

compilerOptions

compilerOptions 是编译选项，可以被忽略，有默认值。常用项：

  • allowJs：默认为 false，是否支持 .js/.jsx 文件；
  • typeRoots：默认编译所有 @types 包，配置后编译指定 typeRoots 下的所有 @types 包；
  • types：只有被列出来的包才会被包含，指定 types 来禁用自动引入 @types 包。

其余选项可查看 TypeScript 编译选项文档。

files / outDir / include / exclude

  • files：指定一个包含相对或绝对文件路径的列表，且总是会被包含在内，exclude 设置无效；
  • outDir：指定的目录下的文件永远会被编译器排除，除非明确地使用 files 将其包含进来；
  • include：包含编译的文件，指定一个文件的 glob 匹配模式列表；
  • exclude：排除编译的文件，指定一个文件的 glob 匹配模式列表，默认排除 node_modules、bower_components、jspm_packages 和 outDir 目录。

glob 匹配模式

  • *：匹配 0/n 个字符；
  • ?：匹配一个任意字符；
  • **/：递归匹配任意子目录。

配置路径别名

先给属性 baseUrl: "."，再在属性 paths 中配置。注意配置时要给 /*，才可以获取对应文件夹下的文件；一般 TS 提示飘红，很可能问题就出在这里。

步骤二：回顾 webpack 的概念与核心

概念

webpack 是静态模块打包工具，处理应用程序时会在内部从一个或多个入口点构建一个依赖图，将项目中所需的每一个模块组合成一个或多个 bundles，这些均为静态资源，用于展示内容。

原理

webpack 是模块捆绑器：将小块代码编译成更大更复杂的代码，运行在 Web 浏览器。

核心

  • 入口（entry）
  • 输出（output）
  • loader
  • 插件（plugin）
  • 模式（mode）
  • 浏览器兼容（browser compatibility）
  • 环境（environment）

模块（模块的离散功能块）

  • 每个模块的表面积都比完整程序小，这使得验证、调试和测试变得微不足道；
  • 良好的模块提供了坚实的抽象和封装边界，因此每个模块在整个应用程序中都具有连贯的设计和明确的目的。

步骤三：使用 Sass at-rules

@use “sass:color”

@use "sass:color" 用于基于现有颜色生成新颜色。

参数：

  • color.red()：用于获取颜色的红色通道；
  • color.green()：用于获取颜色的绿色通道；
  • color.blue()：用于获取颜色的蓝色通道；
  • color.hue()：用于获取颜色的色调；
  • color.saturation()：用于获取颜色的饱和度；
  • color.lightness()：用于获取颜色的亮度；
  • color.whiteness()：用于获取颜色的白度；
  • color.blackness()：用于获取颜色的黑度；
  • color.alpha()：用于获取颜色的 alpha 通道。

方法：

  • color.scale()：流畅地缩放一个或多个属性（不包含本身）；
  • color.change()：将颜色的一个或多个属性设置为新值，返回的是颜色值；
  • color.adjust()：按固定量增加或减少一个或多个属性；
  • 透明度：
    • color.scale()；
    • color.adjust($color, $alpha: -$amount)（保留现有行为）。

@mixin

  • 跟 @include 在一起使用的时候可以把多个样式放在一起；
  • 跟 @each 在一起使用可以搭配变量遍历 meta.keywords（参数）；
  • 跟 @content 在一起，定义整个样式的基调，相当于样式的插槽；
  • 跟 @media 在一起，只有媒体查询的结果符合时，才会应用这一块内容。

@extend 继承

  • selector.unify()：函数返回一个与两个选择器的交集匹配的选择器；
  • selector.extend()：与 @extend 相似，用于单选择器；
  • 占位符选择器 %：仅用于扩展的样式规则。

注意点

  • paths 中的别名要带 /*，否则只能匹配到目录本身，匹配不到目录下的文件，这是 TS 飘红最常见的原因。
  • files 的优先级高于 exclude，被 files 明确列出的文件不会被排除。
  • outDir 目录默认被排除，不要再把它写进 include。
  • @use "sass:color" 是 Sass 模块系统写法，与旧版的全局 lighten()/darken() 函数不同，迁移时注意替换。
