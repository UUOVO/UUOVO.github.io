这篇从 HTML 的定义讲起，依次覆盖实体、文档声明、进制与字符编码、head 元数据、语义化标签、超链接、图片和音视频。结论：HTML 不是编程语言，而是描述页面结构的标记语言；写页面时优先选语义标签，图片和音视频要补齐 alt、controls、loading 等可访问性与性能属性。

一、HTML 是什么

全称是 HyperText Markup Language，即超文本标记语言。它不是编程语言，而是一种用来告知浏览器如何组织页面的标记语言，用来描述网页的表现、展示效果或功能及行为。

  • 超文本（hypertext）是指连接单个网站或多个网站网页的链接。
  • HTML 使用标记（markup）来注明文本、图片和其他内容。
  • HTML 通过标签（tag）标记元素，标签由在 < 和 > 中包裹的元素名组成。
  • HTML 标签里的元素名不区分大小写。

四、进制与字符编码

十进制（日常使用）

  • 特点：满 10 进 1。
  • 单位数字：10 个（0–9）。

二进制（计算机底层的进制）

  • 特点：满 2 进 1。
  • 计数：0、1、10、11、100、101、110、111。
  • 单位数字：2 个（0–1）。
  • 扩展：
    • 所有数据在计算机底层都会以二进制的形式保存。
    • 可以把内存想象为多个小格子组成的容器，每个小格子存储一个 1 或一个 0，这个小格子在内存中被称为 1 位（bit）。
    • 换算：
      • 8bit = 1byte（字节）
      • 1024byte = 1kb（千字节）
      • 1024kb = 1mb（兆字节）
      • 1024mb = 1gb（吉字节）
      • 1024gb = 1tb（特字节）
      • 1024tb = 1pb（拍字节）

八进制

  • 特点：满 8 进 1。
  • 单位数字：8 个（0–7）。

十六进制

一般显示一个二进制数字时，都会转换为十六进制。

  • 特点：满 16 进 1。
  • 计数：0、1、2……9、a、b、c、d、e、f、10、11、12……19、1a、1b、1c、1d、1e、1f、20。
  • 单位数字：16 个（0–f）。

字符编码

  • 所有数据在计算机中存储时都是以二进制形式存储的，文字也不例外。
  • 计算机会将编码转换为字符，供我们阅读。

编码

将「字符」转换为「二进制」码的过程。

解码

将「二进制」码转换为「字符」的过程。

字符集（charset）

编码和解码所采用的规则。

乱码问题

如果编码和解码所采用的字符集不同，就会出现乱码问题。

常见的字符集

  • ASCII
  • ISO88591
  • GB2312
  • GBK
  • UTF-8：开发时使用的字符集都是 UTF-8。

五、head 的内容

元数据：meta 元素

meta 可以提供有关某个 HTML 元素的元信息，比如描述、针对搜索引擎的关键词以及刷新频率。

  • charset：指定网页的字符集。
  • name：指定 meta 元素的类型，说明该元素包含的信息。
    • keywords：表示网站的关键字，可以同时指定多个，使用逗号隔开，与 SEO 相关。
    • description：规定页面的描述。搜索引擎会把这个描述显示在搜索结果中，与 SEO 相关。
    • application-name：规定页面所代表的 Web 应用程序的名称。
    • author：规定文档作者的名字。
  • content：指定实际的数据内容。
  • http-equiv：设置或返回 content 属性中的 HTTP 头部信息。
    • content-type：返回内容的 MIME 类型，通常用于字符集设置。
    • refresh：定义间隔多久后刷新页面。

title 标签

title 的内容会作为搜索结果超链接上的文字显示。

六、表象元素

  • 概念：仅仅影响表象而且没有语义的元素。
  • i 标签：传达传统上用斜体表达的意义，如外国文字、分类名称、技术术语、一种思想等。
  • b 标签：传达传统上用粗体表达的意义，如关键字、产品名称、引导句等。
  • u 标签：传达传统上用下划线表达的意义，如专有名词、拼写错误等。

七、标签的属性

  • 在标签中（开始标签或自结束标签）还可以设置属性。
  • 属性是一个名值对（x=y）。
  • 属性用来设置标签中的内容如何显示。
  • 属性和标签名或其他属性之间应该使用空格隔开。
  • 如果有属性值，属性值应该使用引号引起来。

八、语义化标签

语义对无障碍、SEO（搜索引擎优化）等非常重要。

标题标签

  • h1 ~ h6：分别代表一级标题到六级标题。
    • 从 h1 到 h6 重要性递减，h1 最重要，h6 最不重要。
    • h1 在网页中的重要性仅次于 title 标签，一般情况下一个页面中只会有一个 h1。
    • 一般情况下标题标签只会使用到 h1 ~ h3，h4 ~ h6 很少用。
    • 标题标签都是块元素。
  • hgroup：为标题分组，可以将一组相关的标题同时放入 hgroup。
  • p：表示页面中的一个段落，也是块元素。
  • em（倾斜）：用于表示语音语调的加重。
  • strong（加粗）：表示强调、重要内容。
  • blockquote：表示一个长引用。
  • q：表示一个短引用。
  • br：表示页面中的换行。

块元素和行内元素

  • 块元素（block element）：在页面中独占一行的元素。网页中一般通过块元素来对页面进行布局。
  • 行内元素（inline element）：在页面中不会独占一行的元素。行内元素主要用来包裹文字。

注：

  • 一般情况下会在块元素中放行内元素，而不会在行内元素中放块元素。
  • 块元素中基本上什么都能放。
  • p 元素中不能放任何块元素。
  • 浏览器在解析网页时，会自动对网页中不符合规范的内容进行修正。

布局标签（结构化语义标签）

  • header：表示网页的头部。
  • main：表示网页的主体部分，一个页面中仅一个。
  • footer：表示网页的底部。
  • nav：表示网页中的导航。
  • aside：和主体相关的其他内容（侧边栏）。
  • article：表示一个独立的文章。
  • section：表示一个独立的区块，上边的标签都不能表示时使用 section。
  • div：无语义，表示一个盒子，是主要的布局元素。
  • span：行内元素，无语义，用于在网页中选中文字。

列表

HTML 列表一共有三种：

  1. 有序列表：使用 ol 标签创建带编号的列表，使用 li 表示列表项。
  2. 无序列表：使用 ul 标签创建无序列表，使用 li 表示列表项。
  3. 定义列表：使用 dl 标签创建定义列表，使用 dt 表示定义的内容，使用 dd 对内容进行解释说明。

列表之间可以互相嵌套。

九、超链接

超链接可以让我们从一个页面跳转到其他页面，或者跳到当前页面的其他位置。

使用 a 标签定义超链接。

  • href 属性：指定跳转的目标路径。
    • 值为 javascript:; 时，点击这个超链接什么也不会发生。
    • 值为 # 时，可以跳到当前页面的顶部。
    • 值为 #目标元素的id属性值 时，可以跳转到页面的指定位置。
  • target 属性：指定超链接打开的位置。
    • _self：默认值，在当前页面中打开超链接。
    • _blank：在新页面中打开超链接。
  • id 属性：唯一不重复。每一个标签都可以添加 id，同一个页面中不能出现重复的 id。

a 是行内元素，在 a 标签中可以嵌套除它自身外的任何元素。

相对路径

  • 跳转服务器内部的页面时，一般使用相对路径。
  • 相对路径都会使用 ./ 或 ../ 开头。
  • ./：表示当前文件所在的目录，可以省略不写。
  • ../：表示当前文件所在目录的上一级目录。

十、图片标签

  • 作用：向当前页面中引入一个外部图片。
  • 使用 img 标签引入外部图片，img 是一个自结束标签。
  • img 属于替换元素，介于块元素和行内元素之间，具有两种元素的特点。

img 的属性

  • src：指定外部图片的路径，路径规则和超链接一样。
  • alt：图片的描述。默认情况下不会显示，有些浏览器会在图片无法加载时显示。搜索引擎会根据 alt 中的内容识别图片，如果不写 alt，图片不会被搜索引擎收录。
  • width：图片的宽度，单位是像素。
  • height：图片的高度，单位是像素。
    • 宽度和高度中如果只修改一个，另一个会等比例缩放。
  • loading：指定浏览器是立即加载图像还是延迟加载图像。
    • eager：立即加载。
    • lazy：延迟加载。

注意：

  • 一般情况下，PC 端不建议修改图片大小，需要多大的图片就裁多大。
  • 移动端经常需要对图片进行缩放（大图缩小）。
  • 如果是纯图片页面，不固定图片的宽高，刷新时所有元素宽高都为 0，会导致所有图片都在可视区域，加载变慢。

图片的格式

  • jpeg（jpg）：有损压缩，最流行。支持的颜色比较丰富，不支持透明效果，不支持动图，一般用来显示照片。
  • gif：支持的颜色比较少，支持简单透明，支持动图，适合颜色单一的图片和动图。
  • png：无损静态图像首选。支持的颜色丰富，支持复杂透明，不支持动图，适合颜色丰富、需要复杂透明的图片，专为网页而生。
  • webp：谷歌推出的网页图片格式，具备其他图片格式的优点，而且文件特别小。
  • apng：动态可移植网络图形，是无损动画序列的良好选择（GIF 性能较差）。AVIF 和 WebP 性能更好，但浏览器支持较少。
  • avif：AV1 图像档案格式，性能高且无需版税，支持静态图像，与 PNG 或 JPEG 相比压缩效果更好。使用时应当包含浏览器支持更好的回退格式，即使用 picture 标签。
  • svg：可缩放矢量图形，适用于用户界面元素、图标、图表等。
  • base64：将图片使用 base64 编码转换为字符，通过字符形式引入图片。一般只有需要和网页一起加载的图片才使用 base64。

下面是最基本的图片引入写法。

aspect-ratio

aspect-ratio 控制容器的宽高比，避免产生布局偏移及抖动。

object-fit

object-fit 设定内容应该如何适应到其使用高度和宽度确定的框，避免图片拉伸。

  • fill：把图片压扁到能填充容器宽高，会有拉伸。
  • none：直接把图片放进去，多余部分裁掉，只有一个方向填满。
  • contain：把图片完整放进容器，图片可能会缩小，只有一个方向填满。
  • cover：图片居中显示，宽高都填满，多余部分裁掉，为了填充图片会等比例放大。

配套使用 object-position：基于 object-fit，设置图片实际展示的位置范围，默认 50% 50%。

image-rendering

设置图片在缩放状态下的展示算法。举例：100×100 的图片放大后会模糊，修改 image-rendering 可以变清晰。

  • auto：默认值，Gecko 使用双线性（bilinear）算法重新采样，放大模糊。
  • smooth：使用能最大化图像客观观感的算法缩放图像，放大模糊。
  • high-quality：与 smooth 相同，但更倾向于高质量缩放。
  • crisp-edges：适用于像素艺术作品，例如网页游戏中的图像。
  • pixelated：放大图像时使用最近邻算法，图像看起来像由大块像素组成；缩小图像时与 auto 相同，放大清晰。

浏览器目前只支持 auto、pixelated 和 -webkit-optimize-contrast（Chrome 下的 smooth）。

图片的懒加载

JS 方案实现图片懒加载：

  • 方案 1：监听 onscroll 事件，通过 getBoundingClientRect API 获取图片距离视口顶部的距离，配合当前可视区域的位置实现懒加载。
  • 方案 2：通过 HTML5 的 IntersectionObserver API，配合监听元素的 isIntersecting 属性判断元素是否在可视区内，性能比监听 onscroll 更好。

使用 content-visibility: auto; 实现图片内容的延迟渲染：

  • 该属性控制一个元素是否渲染其内容，允许浏览器省略大量布局和渲染工作，直到需要它为止。
  • 如果该元素当前不在屏幕上，则不会渲染其后代元素。
  • 效果：
    • 图片的外部容器应用 content-visibility 属性后，不断滚动这个容器。
    • 向下滚动时如果图片没渲染出来，滚动条会回弹；每次滚动时图片逐渐渲染，图片还没渲染出来所以滚动不下去。
    • 快速滚动下去时会感觉一卡一卡的。
  • 缺点：无法直接替代图片懒加载。设置了该属性的元素在可视区外只是未被渲染，但其中的静态资源（接口请求）仍会在页面初始化时被全部加载。因此它更像是一个虚拟列表的替代方案。

使用 loading="lazy" HTML 属性实现图片懒加载：

  • 可以延迟加载。
  • 可以添加到 img 标签或 iframe 标签。
  • 设置该属性会告诉浏览器：如果图像位于可视区域，会立即加载；用户滚动到它们附近时再获取其他图像。

使用 decoding="async" 实现图片的异步解码：

  • 用于告诉浏览器使用何种方式解析图像数据。
  • sync：同步解码图像，保证与其他内容一起显示。
  • async：异步解码图像，加快显示其他内容。
  • auto：默认，由浏览器决定使用哪种解码方式。
  • 当不希望图片的渲染解码影响页面其他内容的展示时，使用异步。

loading 和 decoding 一起使用效果更佳。

图片的可访问性处理

  • 所有有意义的 img 元素必须有 alt 属性。
  • 提供替代 alt 的方式：使用 WAI-ARIA 规范提供的 aria-label 和 aria-labelledby 属性为图像提供可访问的名称。
    • WAI-ARIA 是一个为残疾人士等提供无障碍访问动态、可交互 Web 内容的技术规范。
    • tabindex 属性控制元素是否可以聚焦，以及它是否/在何处参与顺序键盘导航。
    • role 属性用来标识元素的语义及作用，例如在容器上使用 role="button" 来模拟按钮。
    • aria-* 属性表示元素的属性或状态。
    • 存在这些属性时，会忽略 alt 属性。
  • 使用辅助技术隐藏装饰图像：
    • 使用 alt=""。
    • 使用 ARIA 属性 role="presentation" 标明元素是装饰、可忽略的图片。
    • 使用 CSS background 的方式呈现这些图片。

图片的异常处理

  • 利用图片加载失败触发 img 标签的 onerror 事件，给加载失败的 img 元素新增一个样式类。
  • 利用新增的样式类配合 img 元素的伪元素，在展示默认兜底图的同时，一起展示 img 元素的 alt 属性。

十一、音视频

audio 标签

  • 支持 IE9 以上。
  • 用来向页面中引入一个外部音频文件。
  • 音视频文件引入时，默认情况下不允许用户自己控制播放停止。

属性：

  • controls：是否允许用户控制播放。
  • autoplay：音频文件是否自动播放。
    • 如果设置了 autoplay，音乐在打开页面时会自动播放。
    • 但目前大部分浏览器都不会自动播放音乐。
  • loop：音乐是否循环播放。

除了通过 src 指定外部文件路径，还可以通过 source 指定文件路径；使用 source 时最好指定源的 type。

video 标签

  • 支持 IE9 以上。
  • 向网页中引入一个视频。

属性：

  • controls：是否允许用户控制播放。
  • autoplay：视频文件是否自动播放。
    • 如果设置了 autoplay，视频在打开页面时会自动播放。
    • 但目前大部分浏览器都不会自动播放。
  • loop：是否循环播放。
  • width / height：播放器宽高。
  • poster："url"，加载等待时显示的图片。
  • muted：静音播放。

注意点

  • img.error::before 只写了 background，没有给尺寸和定位；实际使用时要补 width、height、background-size 或定位，兜底图才会显示。
  • 有意义的图片不要省略 alt：既影响搜索引擎收录，也影响屏幕阅读器。
