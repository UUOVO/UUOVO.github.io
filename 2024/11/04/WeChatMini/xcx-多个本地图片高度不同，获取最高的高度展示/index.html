这篇解决什么问题：一组本地图片高度不一致，直接放进 swiper 会出现高度跳动或留白。做法是先给 image 加上 mode="widthFix" 让高度随宽度自适应，再用 wx.createSelectorQuery() 量出最高的一张，把最高高度回填给容器。

背景与场景

多张本地图片宽度一致、高度不同，需要在 swiper 中逐张展示，并让容器高度按最高的那张图片撑开，避免切换时页面跳动。

一、先搭好 swiper 框架

使用 swiper 组件把图片框架搭建好，image 标签最好加上 『mode=”widthFix”』，让高度跟随宽度自适应。

二、图片动态生成时的处理步骤

  1. 由于高度不一致，通过 『wx.createSelectorQuery()』 获取每一张图片的属性（重点是高度）。
  2. 因为框架初始要渲染，所以代码要写在 onReady 钩子里。
  3. 定义一个存放图片节点的空数组，因为要全局使用，需放在 Page 上方。
  4. 要获取图片存储的选择器，再获取图片的属性（『id 选择器是一对一，类选择器是选全部』）。
  5. swiper 本身有一个 current 属性，需在 data 中初始化。
  6. 定义一个数组，将获取到的图片节点信息 res[0] 存放在里面，为防止报错，最好『给一个初始值（数组 []，对象 null）』。
  7. current 要动态获取。
  8. 判断是否有图片，有的话就将定义的数组赋值给图片节点存放的数组。
  9. 获取到图片的高度后，首先要在 data 中初始化，然后再动态传递给初始化变量。
  10. 查看显示的长度是否异常（从执行的函数开始往下找）。
  11. 异步场景下，使用延时器加载。

三、图片非动态的情况

如果图片不是动态生成的，直接用 CSS 样式配合 mode 控制即可，不需要再走选择器测量。

注意点

  • 高度必须在渲染完成后才能量到，所以测量代码放在 onReady；如果图片仍异步渲染，再加延时器。
  • 用 selectAll 才能一次拿到所有图片节点，select 只会拿到一个。
  • data 中的数组、对象要给初始值，否则后续赋值前访问会报错。
  • 使用了 mode="widthFix" 后高度由宽度决定，容器宽度变化时需要重新测量。
