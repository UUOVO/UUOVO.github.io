这篇解决什么问题：把 Vue3 组件开发中最常用、也最容易混淆的基础知识集中梳理一遍，包括组件怎么注册、Props 怎么声明和校验、事件怎么抛和收、组件上的 v-model 怎么实现、透传属性和插槽怎么用，以及依赖注入、异步组件、动态组件和 DOM 模板的限制。

背景：组件是 Vue 应用的基本单元

一个页面可以拆成多个组件，组件之间通过 Props 向下传数据、通过事件向上通知、通过插槽分发内容。下面按“注册 → 传值 → 通信 → 分发 → 复用”的顺序逐项说明。

组件名格式统一使用 PascalCase。

单根节点

单根节点组件有自动 attribute 透传行为。

  • 设置 inheritAttrs: false 可以禁用 Attributes 继承。
  • 使用 v-bind="$attrs" 可以让透传的 attribute 指定到目标元素。

多根节点

一个组件有多个根节点时，没有自动 attribute 透传行为，必须使用 v-bind="$attrs" 让透传的 attribute 指定到目标元素。
