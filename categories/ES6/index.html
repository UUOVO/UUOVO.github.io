ES6
Promise/async 与es5总结
  • 10/31
  • 17:15
  • 1.8k

三种异步写法解决的是同一个问题：拿到结果之后那段代码放在哪里。ES5 写在回调参数里，Promise 挪到 .then 里形成链，async/await 则是 Promise 的语法糖——编译之后依然是 Promise。这篇文章先对照三种写法，再用一份手写的 LcPromise 拆解 .then / .catch 的内部原理：状态、成功回调队列、失败回调队列。文末单独列出这份实现里的几处笔误，方便对照修正。

Date
  • 10/31
  • 15:54
  • 1.3k

结论先行：日常用 Date 只有三件事要搞清楚——怎么构造、怎么取值、怎么算时区。构造时记住「月份从 0 开始、日传 0 拿到上个月最后一天」；取值时 getMonth() 返回 0–11；只要涉及跨时区展示，就必须先用 getTimezoneOffset() 把本地时间换算成零时区时间，再按目标时区的偏移加减，最后别忘了夏令时。

Generator和 Iterators
  • 10/31
  • 15:54
  • 990

结论先行：Iterator 是一套「用 next() 一步步取值」的协议，每次返回 { value, done }；Generator（function* 加 yield）则是自动实现这套协议的函数——调用它不会执行函数体，而是返回一个迭代器，每调一次 next() 就从上次停下的位置继续跑到下一个 yield。

Module
  • 10/31
  • 15:54
  • 867

结论先行：ES6 模块的功能主要由两个命令构成——export 输出、import 输入。默认输出用 export default，引入时不用花括号、可以另起名字；命名输出必须用 { } 按名字引入，可以用 as 改名。需要按需加载、条件加载或动态路径时，用动态 import()（异步），而不是 require()（同步）。

async/await
  • 10/31
  • 15:54
  • 878

结论先行：async 是 Generator 函数的语法糖，被它修饰的函数调用后一定返回 Promise 对象；await 负责等待它右边的表达式——右边是 Promise（或 thenable）就取出结果，不是就直接返回该值。所以写异步代码只要记住三件事：async 返回 Promise、await 取结果、出错用 try...catch 兜住。

Promise(resolve,reject)
  • 10/31
  • 15:54
  • 2k

结论先行：Promise 只有 pending（进行中）、fulfilled（已成功）、rejected（已失败）三种状态，并且只能从 pending 单向变成后两种，一旦定型就不会再变。then / catch / finally 负责接收结果，all / allSettled / any / race 负责组合多个 Promise。而 async/await 的执行顺序题，本质是数「返回值类型决定要等几轮微任务」。

Set/Map构造函数
  • 10/31
  • 15:54
  • 1.6k

结论先行：Set 是「值的集合」，天生去重；Map 是「键值对的集合」，键可以是任意类型。两者都实现了 Symbol.iterator，所以可以直接用 [...] 转数组、用 for...of 或 forEach 遍历；但它们本身都没有 map / filter 方法，需要先转成数组处理，再转回 Set 或 Map。

函数的拓展
  • 10/31
  • 15:54
  • 503

结论先行：ES6 给函数补了三块内容——参数默认值、length 属性的新规则、箭头函数。默认值让可选参数不用再手写判空；length 只统计默认值之前的形参；箭头函数没有自己的 this，用在回调里很省事，用在对象方法或需要动态 this 的场景就是坑。

字符串
  • 10/31
  • 15:54
  • 3.2k

ES6 对字符串的改造可以分三层看：最底层是 Unicode 的表示与转义（\uxxxx、\u{...}、代理对），中间层是遍历与序列化行为（for...of 按码点遍历、JSON.stringify 对孤立代理的转义），最上层是模板字符串、标签模板和一批 String 新方法（includes、startsWith、padStart、replaceAll、at 等）。下面按这三层顺序整理，每个 API 保留原有的语法、参数、返回值和示例输出，容易出错的边界单独说明。

对象的拓展
  • 10/31
  • 15:54
  • 2k

ES6 对对象的改动集中在四块：属性名可以直接写表达式、方法的 name 属性更准确、属性遍历有了明确顺序、以及 super、扩展运算符、Object.assign、Object.getOwnPropertyDescriptors 等新能力。这篇按”怎么定义 → 怎么遍历 → 怎么继承和拷贝 → 新增方法 → 常见用途”的顺序整理，示例结果保留原笔记的写法，容易踩坑的地方单独标注。
