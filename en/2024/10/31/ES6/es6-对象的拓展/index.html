ES6 对对象的改动集中在四块：属性名可以直接写表达式、方法的 name 属性更准确、属性遍历有了明确顺序、以及 super、扩展运算符、Object.assign、Object.getOwnPropertyDescriptors 等新能力。这篇按”怎么定义 → 怎么遍历 → 怎么继承和拷贝 → 新增方法 → 常见用途”的顺序整理，示例结果保留原笔记的写法，容易踩坑的地方单独标注。

背景：对象字面量在 ES5 里的限制

ES5 的对象字面量里，属性名只能写标识符或字符串字面量，方法名也只能固定写死；遍历顺序在规范里也没有明确规定。ES6 放开了前两点（计算属性名、简洁方法），并把遍历顺序标准化为”数值键 → 字符串键 → Symbol 键”，下面的内容基本都围绕这些变化展开。

1. 属性名表达式

一句话：属性名除了直接用标识符，还可以用 [] 包一个表达式，运行时求值后再作为键名。

注意：『属性名表达式如果是一个对象，默认情况下会自动将对象转为字符串 [object Object]』，所以 obj[{}] 和 obj[{ a: 1 }] 写到的是同一个键。

一句话：对象字面量里同样可以用 [] 写计算属性名，方法名也可以这样写。

2. 方法的 name 属性

一句话：函数的 name 属性返回函数名，对象方法也是函数，所以方法名同样能读到。

一句话：用取值函数（getter）和存值函数（setter）定义的方法，name 落在该属性描述符的 get 和 set 函数上，分别是 "get foo" 和 "set foo"。

一句话：还有两类特殊情况——bind 创造的函数，name 返回 bound 加上原函数名；Function 构造函数创造的函数，name 返回 anonymous。

一句话：对象方法名是 Symbol 值时，name 返回该 Symbol 的描述字符串。

3. 属性的遍历

一句话：下面五种方式覆盖面不同，区别只在”是否包含继承属性、是否包含不可枚举属性、是否包含 Symbol 键”。

  • for...in：遍历对象自身的和继承的可枚举属性（不含 Symbol 属性）
  • Object.keys(obj)：返回一个数组，包括对象自身的（不含继承的）所有可枚举属性（不含 Symbol 属性）的键名
  • Object.getOwnPropertyNames(obj)：返回一个数组，包含对象自身的所有属性（不含 Symbol 属性，但是包括不可枚举属性）的键名
  • Object.getOwnPropertySymbols(obj)：返回一个数组，包含对象自身的所有 Symbol 属性的键名
  • Reflect.ownKeys(obj)：返回一个数组，包含对象自身的（不含继承的）所有键名，不管键名是 Symbol 或字符串，也不管是否可枚举

一句话：除 for...in 外，这些方法遍历时都遵循同一顺序——先数值键（按数值升序），再字符串键（按加入时间升序），最后 Symbol 键（按加入时间升序）。

注意：数值键虽然按数字大小排序，返回的却是字符串 '2'、'10'，因为它们本质是字符串键里的”类整数键”，用 typeof 检查会得到 string。

4. super 指向当前对象的原型对象

一句话：对象方法里的 super 指向该对象的原型对象，用来调用原型上的同名方法。

注意：这里输出的是 world 而不是 hello。super.foo() 只是”去原型上找 foo 这个函数”，函数执行时的 this 仍然是 obj，所以 this.x 取到 obj.x。另外 super 只能出现在对象方法或 Class 方法里，写在普通函数里是语法错误。

5. 扩展运算符：拷贝与展开

一句话：对象的扩展运算符把源对象的可枚举自有属性浅拷贝到新对象里，效果等同于 Object.assign({}, src)。

  • 对象的扩展运算符等同于使用 Object.assign() 方法。

6. 对象的新增方法

Object.is(值1, 值2)：判断两个值是否严格相等

一句话：行为与 === 基本一致，只有两处不同——+0 不等于 -0，NaN 等于自身。

Object.assign()：对象合并（浅拷贝）

一句话：把后面所有源对象的可枚举属性复制到第一个参数（复制存放地）上，并返回这个目标对象。

  • 多参：Object.assign(复制存放地, 被复制对象, 被复制对象, ...)
  • 一参：直接返回该参数
    • undefined、null 做首参则报错
    • 参数非对象时，先转成对象再返回
    • 不拷贝 enumerable: false 的属性

Object.getOwnPropertyDescriptors() — ES8

一句话：获取一个对象的所有自身属性的描述符，返回值的键是属性名，值是对应的描述符对象。

调用形式是 Object.getOwnPropertyDescriptors(obj)。

注意

  1. 浅拷贝：只要修改其中一个，其它的也会改变。
  1. 同名属性替换：复制存放的对象属性如果跟被复制的对象属性一样，会被替换。
  2. 可以处理数组，但是会把数组视为对象。

注意：第 1 条之所以两边互相影响，是因为 a 的值是对象，拷贝的只是引用；要彻底隔离得做深拷贝。第 3 条指目标对象是普通对象时，数组会按索引被当成对象属性复制。

常见用途

一句话：Object.assign 最常见的四个用途是加属性、加方法、克隆对象和合并多个对象。

注意：第 3 种写法是浅克隆，只能拷贝可枚举的自有属性，原型上的属性靠 Object.create(originProto) 继承过来，不会真的复制。

踩坑与注意点

  1. 计算属性名里放对象会先转成字符串，obj[{}] 实际是 obj["[object Object]"]。
  2. super.foo() 不会改变 this，函数里的 this 仍指向当前对象，所以取到的是对象自身的属性。
  3. Object.assign 是浅拷贝、不拷贝不可枚举属性，首参为 undefined / null 会抛 TypeError。
