这篇解决 Windows 上（重新）安装 Git 后报 fatal: open /dev/null or dup failed: No Such file or directory 的问题。根本原因是系统缺少 Null 服务或 null.sys 驱动文件异常，处理顺序是：修注册表和服务 → 修系统文件 → 覆盖升级安装 → 最后处理 Git 的 safe.directory 提示。

  2. 如果本机已有这一项，把默认项的数值改为 1。

第 5 步：仍未解决时，覆盖升级安装 Windows

  1. 下载并运行 MediaCreationToolW11。
  2. 在「选择语言和版本」界面选择正确的系统版本（通常默认与当前系统一致，不用选择）；在「选择要使用的介质」界面选择「ISO 文件」。
  3. 选择一个位置保存该文件（任意位置），下载完成后双击打开，找到 setup.exe，鼠标双击运行。
  4. 在「你想执行哪种类型的安装」界面，选择「升级：安装 Windows 并保留文件、设置和应用程序」。
  5. 等待安装重启，完成后执行 sfc /scannow，出现第 4 步的结果即为完成。
  6. 重新安装 Git 和 TortoiseGit（重启次数较多，扫描和安装时间较长，请耐心等待）。

第 6 步：处理重装 Git 后的 safe.directory 提示

重装 Git 时一定要卸载干净：从「设置 - 应用」中卸载，并确认 C 盘隐藏目录 ProgramData 中的 Git 是否还在，存在说明卸载不干净。
