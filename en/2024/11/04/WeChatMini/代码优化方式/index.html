结论先行：大部分 if / else 和三目表达式都可以用运算符或查表法压平——缺省值用 ||、??，条件执行用 &&，批量赋默认值用 &&=、||=、??=；再复杂一点的判断，就把分支抽成函数、把数据存进数组或对象，用”取键”代替”写分支”。

背景与场景

小程序页面里经常出现一串条件判断：按钮是否禁用、表单是否必填、某个状态对应什么文案。这类代码写起来快，但堆多之后可读性很差，改一个条件要顺着表达式数括号。下面按”运算符替代”和”结构重构”两类整理。

一、用逻辑运算符替代三目

1. 逻辑或 ||

  • 含义：用 Boolean 把左边转成布尔值，『若为 true 返回左值，若为 false 返回右值』。
  • 原语句：leftData ? leftData : rightData
  • 简化：leftData || rightData
  • 适合场景：isClick ? '' : 'hidden'

2. 逻辑与 &&

  • 含义：同样先用 Boolean 转换左边，『若为 false 返回左值，若为 true 返回右值』。
  • 原语句：leftData ? rightData : leftData
  • 简化：leftData && rightData

3. 空值合并运算符 ??

  • 含义：ES2020 新增，当左侧的操作数为 null 或 undefined 时返回右侧操作数，否则返回左侧操作数。
  • 关键：『只要 leftData 不为 undefined 或 null 就返回 leftData』。
  • 原语句：leftData !== null && leftData !== undefined ? leftData : rightData
  • 简化：leftData ?? rightData

|| 会把 0、''、false 当成”无值”，所以这种情况用 ??。而 ?? 只认 null 和 undefined。

二、逻辑运算符和赋值表达式（ES12）

1. &&=

含义：x &&= y 等价于 x && (x = y)，即『当 x 为 true 时，x = y』。

2. ||=

含义：x ||= y 等价于 x || (x = y)，即『当 x 为 false 时，x = y』。

3. ??=

含义：x ??= y 等价于 x ?? (x = y)，即『当 x 为 null 或 undefined 时，x = y』。

场景三：表单校验改为查表

if / else 或 switch 叠加校验逻辑时，把提示信息、校验的 key 和是否必填（必填可以借助 ts 的类型校验忽略或排除）写成一个数组对象；再判断该 key 对应的 value 是否为 undefined，是就提示并返回。

注意点：

  • 『数组一存放 key 和 value 的数组对象，数组二存放要校验的 key 和提示信息』。
