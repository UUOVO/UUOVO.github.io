结论先行：ES6 模块的功能主要由两个命令构成——export 输出、import 输入。默认输出用 export default，引入时不用花括号、可以另起名字；命名输出必须用 { } 按名字引入，可以用 as 改名。需要按需加载、条件加载或动态路径时，用动态 import()（异步），而不是 require()（同步）。

async/await
  • 10/31
  • 15:54
  • 878

结论先行：async 是 Generator 函数的语法糖，被它修饰的函数调用后一定返回 Promise 对象；await 负责等待它右边的表达式——右边是 Promise（或 thenable）就取出结果，不是就直接返回该值。所以写异步代码只要记住三件事：async 返回 Promise、await 取结果、出错用 try...catch 兜住。

Promise(resolve,reject)
  • 10/31
  • 15:54
  • 2k

结论先行：Promise 只有 pending（进行中）、fulfilled（已成功）、rejected（已失败）三种状态，并且只能从 pending 单向变成后两种，一旦定型就不会再变。then / catch / finally 负责接收结果，all / allSettled / any / race 负责组合多个 Promise。而 async/await 的执行顺序题，本质是数「返回值类型决定要等几轮微任务」。

Set/Map构造函数
  • 10/31
  • 15:54
  • 1.6k

结论先行：Set 是「值的集合」，天生去重；Map 是「键值对的集合」，键可以是任意类型。两者都实现了 Symbol.iterator，所以可以直接用 [...] 转数组、用 for...of 或 forEach 遍历；但它们本身都没有 map / filter 方法，需要先转成数组处理，再转回 Set 或 Map。

函数的拓展

结论先行：ES6 给函数补了三块内容——参数默认值、length 属性的新规则、箭头函数。默认值让可选参数不用再手写判空；length 只统计默认值之前的形参；箭头函数没有自己的 this，用在回调里很省事，用在对象方法或需要动态 this 的场景就是坑。
