这篇把 HBuilderX 里真正提效的快捷键按用途分成几组：多光标与列选择、跳转定义、全局搜索、标签包围与反包围、批量合并与注释，最后附上代码块（js/dom/vue/uni-app）、Emmet 和 Markdown/Mermaid 的速查表。适合放在手边，遇到重复劳动时来查一条。

背景：为什么要整理快捷键

uni-app 项目里模板、脚本、样式混在一个文件中，改一处往往要同时动好几行。多光标、列选择、标签包围这几个能力用熟以后，重复的机械编辑能少一半。下面按使用场景分组，每组只写“按什么键、得到什么效果”。

一、多光标

  • Ctrl + 鼠标左键：增加一个光标
  • Ctrl + 鼠标右键：取消一个光标或选区
  • Ctrl + e：选中相同的词做批处理
  • Ctrl + Shift + e：选中相同的词做批处理，并智能识别语法，剔除不相干的词

二、列选择

  • Alt + 鼠标拖选
  • 或者用 Ctrl + Alt + ↑ 或 ↓

三、转到定义

  • Alt + d
  • Alt + 鼠标左键单击
  • Ctrl + Alt + 左键：把定义处的代码打开在另一侧
  • Alt + ← 或工具栏上的 <：回到上一个光标位置
  • 输入 0 跳转到首行，输入 $ 跳转到最后一行

四、文件与搜索

  • Ctrl + p：快速打开文件
  • Ctrl + Tab：查看编辑器中打开的所有文件列表
  • Ctrl + Shift + o：查找索引符号
  • 选中一段文本后按 Ctrl + Shift + f：对局部的文本进行搜索、替换、全选

五、在选中区域外围添加标签

选中首尾 tag 后按 Ctrl + ]，即可给选区套上标签。

在 js 中按 Ctrl + ]，则可以包围 if、for 等语句块。

六、反包围

双击 tag 开头选中 tag，再按下 Ctrl + Shift + ]，会去掉当前 tag 并自动处理缩进。

七、扩大选区

= 是 + 的默认键，所以 Ctrl + = 就是 Ctrl 和 + 键一起按下。

八、交换选区内容

先选中第一个要交换的内容，按下 Ctrl 再选中第二个要交换的位置，最后按 Ctrl + Shift + x 完成交换。

九、撤销最后一个多选区或多光标

  • 双击选中内容
  • 按 Ctrl + e 选中相同词
  • 按 Ctrl + Shift + z 不再选中最后一个词
  • 多选了一个词时，Ctrl + 鼠标右键 取消一个选区
  • Alt + Shift + e 跳过当前词选下一个词

十、批量合并行

  • 双击 { 内侧选中 class
  • 按 Ctrl + 双击 选中另一个 class
  • 按反格式化 Ctrl + Shift + k，把每个 css 的区块代码都合并为一行

Ctrl + k 是格式化代码，Ctrl + Shift + k 则是合并为一行。

十一、同时注释 if 段首尾

  • 双击 if 选中 if 代码块
  • 按 Ctrl + \ 在选区首尾加光标，变成多光标模式
  • 按 Ctrl + / 注释掉选区首尾行

Emmet

Emmet 使用类似于 CSS 选择器的语法来描述元素在生成的树和元素属性中的位置，缩写时不能有空格。

嵌套运算符：

  • >：元素随着 > 一层一层向里嵌套
  • +：元素放置在同一水平上
  • ^：^ 后携带的元素，可以让 > 嵌套的元素向上一层移动，一个 ^ 向上移动一层
  • *：输出几次
  • ()：分组

属性运算符：

  • 标签后带 #：生成 id 选择器
  • 标签后带 .：生成 class 选择器，可混合写和连写
  • 标签后带 []：生成的语法带有 [] 中所写的属性值
  • 项目编号 $
    • li.item$*5：单个从 1 开始编号
    • li.item$$$*5：多个用 0 来替代数字
    • li.item$@-*5：从大到 1 开始编号
    • li.item$@3*5：从 3 开始编号，生成五个
    • li.item$@-3*5：从大到 3 开始编号
  • 标签后带 {}：向元素添加文本

json 优化

  • 中文符号免干扰输入
  • 回车时自动补全行尾逗号
  • 保存时自动删除数组或键值对结尾的多余逗号
  • keyValue 代码块
  • 智能双击，快速选中数组或键值对
  • 快速重复插入
  • Ctrl + Insert 或 Ctrl + Shift + r
  • 语法提示
  • 保存时自动校验语法

markdown 优化

  • 标题：敲 h2 后按 Tab 即可生成二级标题
  • 图片：输入 img 后按 Tab
  • 链接：输入 a 后按 Tab
  • 表格：输入 table3*3 后按 Tab，表示生成 3 行 3 列的表格，行首生效
  • 分割线：输入 hr 后按 Tab
  • 代码块：输入 code 后按 Tab，行首生效
  • day 后按 Tab，插入当前日期。注意 day 需在行首或前面有空格
  • time 后按 Tab，插入当前时间。注意 time 需在行首或前面有空格
  • 文字加粗：输入 b 后按 Tab
  • 文字倾斜：输入 i 后按 Tab
  • 注释：快捷键 Ctrl + / 快速插入注释

踩坑与注意点

  1. 快捷键可能随 HBuilderX 版本和自定义键位变化，若按键无效，先去“工具 → 自定义快捷键”确认。
  2. Alt + d、Ctrl + e 这类单键组合容易和输入法或系统快捷键冲突，冲突时优先改用菜单里的同名功能验证。
