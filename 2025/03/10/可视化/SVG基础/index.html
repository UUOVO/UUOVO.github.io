这篇按「画布 → 图形 → 路径 → 样式 → 文字 → 渐变 → 裁剪 → 动画」的顺序把 SVG 的基础过一遍，每个知识点都配可直接粘贴运行的代码。目标是看完就能手写一个图标或一段路径动画，遇到不熟的属性也能按章节回查。

背景

SVG 是用 XML 描述二维图形的格式，浏览器直接解析、可无损缩放、能被 CSS 和 JS 操控。图表中的自定义图形、图标、形变动画，最终都会落到下面这些标签和属性上。

version：指明 SVG 的版本和规范

目前只有 1.0 和 1.1 版本。这个属性只做说明，对渲染没有影响。

xmlns 和 xmlns:xlink

  • svg 是使用 xml 格式定义的图形，svg 文件是纯粹的 xml 文件
  • xmlns 用于声明命名空间，在该声明下的所有子标签都属于这个空间
  • xmlns:xlink 表示前缀为 xlink 的标签和属性，应该由理解该规范的 UA 使用 xlink 规范来解释
  • 注解：UA 是 User Agent 的简称。User Agent 是 HTTP 协议中的一部分，属于头域的组成部分。通俗地讲，UA 是一种向访问网站提供你所使用的浏览器类型、操作系统、浏览器内核等信息的标识。通过这个标识，用户所访问的网站可以显示不同的排版，从而提供更好的体验或进行信息统计

第三步：掌握 path 命令

注意：『所有命令中大写为绝对定位，小写为相对定位』

path 字母意义（简）

  • M = Move to 移动
  • L = Line to 线
  • H = Horizontal Line to 水平线
  • V = Vertical Line to 垂直线
  • Q = Quadratic Bezier Curve to 二次贝塞尔曲线
  • T = Smooth Quadratic Bezier Curve to 延长二次贝塞尔曲线
  • C = Curve to 三次贝塞尔曲线
  • S = Smooth Curve to 三次贝塞尔曲线延长
  • A = Elliptical Arc 椭圆弧
  • Z = close path 关闭路径

直线命令

M：移动

  • 路径的起始点，用来指明画笔从何处开始绘制（还没画）
  • 每一段路径都必须以 M 开头，如果有多个 M 命令则表示新路径开始
  • 语法：绝对定位为 M x y，相对定位为 m x y
  • 参数：x、y 为 X 轴和 Y 轴坐标

L：画线

  • 绘制一个点，并和之前的点（也就是 L 命令前面的点）连成一条直线
  • 与 M 命令结合就是从 M 点到 L 点形成一条直线
  • 语法：绝对定位为 L x y，相对定位为 l x y
  • 参数：x、y 为 X 轴和 Y 轴坐标

示例 1：从起始点 (50,50) 画一条到 (250,50) 的直线，再从起始点 (50,100) 画一条到 (250,100) 的直线。

注意：『M 命令为多个时，后面的 M 命令为新线段的起始点』

示例 2：从起始点 (50,50) 画一条到 (250,50) 的直线。

注意：『M 命令后面连续跟着多个坐标点，除第一个坐标点外，后面的全部默认为隐式的 L 命令』

示例 3：从起始点 (50,50) 画一条到 (250,200) 的直线，然后再画一条从 (250,200) 到 (250,250) 的直线。

注意：『多个 L 命令连续出现时可以省略后面的 L 命令，并且前一个 L 与后一个 L 相连』

H：水平线

  • 从前一个点绘制一条水平的直线，与前一个点 y 相同、x 不同
  • 语法：绝对定位为 H x，相对定位为 h x
  • 参数：x 为 X 轴坐标
  • 注意：『连续的 H 命令取最大值』，例如 d="M50 20 H250 100"，会直接从 (50,20) 画到 (250,20)

示例：从起始点 (50,50) 画一条 X 坐标为 250 的水平直线，即把 (50,50) 和 (250,50) 连接起来。

V：垂直线

  • 从前一个点绘制一条垂直的直线，与前一个点 x 相同、y 不同
  • 语法：绝对定位为 V y，相对定位为 v y
  • 参数：y 为 Y 轴坐标
  • 注意：『连续的 V 命令取最大值』，例如 d="M50 20 V250 100"，会直接从 (50,20) 画到 (50,250)

示例：从起始点 (50,50) 画一条 Y 坐标为 250 的垂直直线，即把 (50,50) 和 (50,250) 连接起来。

Z：闭合路径

  • 从当前点画一条直线回到路径的起始点
  • 语法：绝对定位为 Z，相对定位为 z
  • 参数：无

示例：从起始点 (50,50) 画一条 X 坐标为 200 的水平直线，然后再画一条到 Y=200 的垂直线，最后闭合路径。

第四步：设置填充和轮廓

fill：填充

  • 用于填充图形、文本的颜色
  • 语法：fill="color" 或者 style="fill:color"
  • 『不设置时，默认填充为黑色』
  • 取消默认填充：fill="none"

fill-opacity

用于设置颜色的透明度。

fill-rule

用来设置复杂形状的填充规则。填充方式大致是判断图形绘制结束后中间闭合的部分填不填充，图形本身一定会填充。

  • nonzero：默认值，大部分中间会填充
  • evenodd：大部分中间不填充

nonzero 的判定：判断一个点是否在图形内，从该点做任意方向的一条射线，然后检测射线与图形路径的交点情况。从 0 开始计数，路径从左向右（顺时针）穿过射线则计数加 1，从右向左（逆时针）穿过射线则计数减 1。得出计数结果后，如果是 0 则认为点在图形外部，否则认为在内部。

evenodd 的判定：从该点做任意方向的一条射线，然后检测射线与图形路径的交点数量。如果结果是奇数则认为点在内部，是偶数则认为点在外部。

踩坑与注意点

  1. lengthAdjust 是大小写敏感的驼峰属性，不要写错。
  2. tref、use、textPath 示例中的 xlink:href 需要 svg 根节点保留 xmlns:xlink 声明，否则引用会失效。
  3. 示例里的 // <--- 只是标注位置，放在标签内部并不是合法的 XML 注释，复制使用时需要删掉。
  4. polyline 和 polygon 默认会被填充，忘记加 fill="none" 时线条会被一块实心色块盖住。
  5. 旋转默认绕画布原点 (0,0) 而不是元素中心，需要绕自身旋转时必须配合 transform-origin。
  6. stroke-dashoffset 依赖 stroke-dasharray，没设 dasharray 时偏移不会生效。
  7. A 命令示例的 d 中，M 后面多带了一组坐标（如 M10 50 50 50 A ...），这组坐标会被当作隐式的 L 命令。若不需要前面那段直线，可以把它删掉。
