结论先行

字符串、Date、Math、包装类和 JSON 是日常业务里复用频率最高的一组内置能力：字符串方法负责查找与截取，Date 负责时间戳和日期字段，Math 负责取整与随机数，包装类解释为什么基本类型能调用方法，JSON 和 eval() 负责字符串与对象的互转。这篇按这五类整理常用方法、参数和返回值，方便随手查阅。

背景

这些 API 都属于 JS 内建对象，不需要引入任何依赖。真正容易出错的是参数含义和边界：slice 的结束索引不含、getMonth() 从 0 开始、Math.random() 取不到 1、substring 不接受负数。下面在列方法的同时把这些边界一并说明。

步骤 1：字符串的常用方法

先看获取长度、按索引取字符和字符编码互转：

  • length：获取字符串的长度。
  • charAt()：返回字符串中指定位置的字符。
  • charCodeAt()：根据索引获取指定的字符编码。
  • String.fromCharCode()：根据字符编码获取字符。

indexOf() 和 lastIndexOf() 用于从一个字符串中检索是否含有指定内容：

  • 如果字符串中含有该内容，则返回其第一次出现的索引，没有找到返回 -1。
  • 可以指定第二个参数，表示开始查找的位置。

slice() 从一个字符串中截取指定内容，并将截取到的内容返回，不会影响原字符串：

  • 第一个参数：截取开始的位置（包括开始）。
  • 第二个参数：截取结束的位置（不包括结束）。
  • 第二个参数可以省略，省略时一直截取到最后。
  • 可以传负数，负数表示从后往前数。

常用方法如下：

  • getDate()：当前日期对象是几日（1-31）。
  • getDay()：返回当前日期对象是周几（0-6）。
    • 0 表示周日。
    • 1 表示周一，以此类推。
  • getMonth()：返回当前日期对象的月份（0-11）。
    • 0 表示一月，以此类推。
  • getFullYear()：获取当前日期对象的年份。
  • getHours()：返回 Date 对象的小时（0 ~ 23）。
  • getMinutes()：返回 Date 对象的分钟（0 ~ 59）。
  • getSeconds()：返回 Date 对象的秒数（0 ~ 59）。
  • getMilliseconds()：返回 Date 对象的毫秒（0 ~ 999）。
  • getTime()：返回当前日期对象的时间戳。
    • 时间戳指的是从格林威治标准时间的 1970 年 1 月 1 日 0 时 0 分 0 秒，到现在时间的毫秒数。
    • 计算机底层保存时间都是以时间戳的形式保存的。
  • Date.now()：获取当前代码执行时的时间戳。

步骤 3：Math 数学工具

Math 属于一个工具类，不需要创建对象，它里边封装了数学运算相关的常量和方法。

  • Math.PI：常量，圆周率。
  • Math.abs()：绝对值运算。
  • Math.ceil()：向上取整，小数位只要有值就自动进 1。
  • Math.floor()：向下取整，小数部分会被舍掉。
  • Math.round()：四舍五入取整。
  • Math.random()：生成一个 0-1 之间的随机数。
  • Math.pow(x, y)：求 x 的 y 次幂。
  • Math.sqrt()：对一个数进行开方。
  • Math.max()：求多个数中的最大值。
  • Math.min()：求多个数中的最小值。

步骤 5：JSON

JSON（JavaScript Object Notation，JS 对象表示法）是一个特殊格式的字符串，可以被任意语言识别，并且可以转换为任意语言中的对象，在开发中主要用来做数据交互。

  • 如果需要兼容 IE7 及以下的 JSON 操作，则可以通过引入一个外部的 js 文件来处理。
  • JS 中的对象只有 JS 自己认识，其他语言都不认识。
  • JSON 和 JS 对象的格式一样，只不过 JSON 字符串中的属性名必须加双引号，其他的和 JS 语法一致。

JSON 分为两类：

  1. 对象 {}。
  2. 数组 []。

JSON 中允许的值有六种：

  1. 字符串
  2. 数值
  3. 布尔值
  4. null
  5. 对象
  6. 数组

步骤 6：eval()

eval() 可以用来执行一段字符串形式的 JS 代码，并将执行结果返回。

如果使用 eval() 执行的字符串中含有 {}，它会将 {} 当成是代码块。如果不希望将其当成代码块解析，则需要在字符串前后各加一个 ()。

eval() 的功能很强大，可以直接执行一个字符串中的 JS 代码，但是在开发中尽量不要使用：它的执行性能比较差，而且具有安全隐患。

踩坑与注意点

  • slice() 的第二个参数是结束索引且不包含该位置；substr() 的第二个参数是长度，两者不要混用。
  • substring() 会把负数修正为 0，并且会自动交换两个参数的位置。
  • getMonth() 返回 0-11，展示月份时通常要 +1；getDay() 返回 0 表示周日。
  • Math.random() 的取值范围是 [0, 1)，取不到 1；用 Math.round() 生成区间随机数时，两端的概率与中间不同。
  • 包装类对象和基本类型不要混用，new Number(1) 是对象，直接比较时会得到意外结果。
  • JSON 字符串的属性名必须使用双引号，单引号和无引号都不是合法 JSON。
  • eval() 会执行任意字符串代码，存在注入风险，能用 JSON.parse() 就不要用 eval()。
  • 原文包装类示例说明“不会报错结果为 undefined”，这只在非严格模式下成立；严格模式下给基本类型添加属性会抛出 TypeError。
