这篇是 Less 的速查手册，按「基础语法 → 变量 → 混合 → 函数工具」组织，目标是让你能把一段原生 CSS 平滑改写成 Less。结论：Less 是 CSS 的增强版，新增变量、mixin、运算和内置函数，但最终仍要编译成 CSS 才能在浏览器执行；单行注释不会进入编译结果。

背景：Less 是什么

  • CSS 的预处理语言，可以理解为 CSS 的增强版。
  • 新特性包括对变量的支持、对 mixin 的支持等。
  • 语法大体和 CSS 一致，但增加了许多对 CSS 的扩展。
  • Less 必须转成 CSS 才能在浏览器上执行。
  • 单行注释的内容不会被解析到 CSS 中。

e：字符串转义

  • 参数：要转义的字符串。

%：设置字符串格式

参数：

  • 带有占位符的字符串。
  • 用于替换占位符的值。

返回值：格式化后的字符串。

占位值：

  • d、D、a、A：可以替换为任何类型的参数；与字符串结合时，会使用整个字符串（包括引号），不会转义。
  • s、S：可以替换为任何表达式；与字符串结合时，使用字符串值并省略引号。
  • 注：小写占位符保留特殊字符，大写会转义特殊字符，()'~! 和空格会编码为 %20。

replace：替换字符串中的文本

参数：

  • string：要搜索和替换的字符串。
  • pattern：要搜索的字符串或正则表达式模式。
  • replacement：用来替换匹配模式的字符串。
  • flags（可选）：正则表达式标志。

返回：带有替换值的字符串。

列表函数

  • length：返回列表的长度。
    • 参数 list：逗号或空格分隔的值列表。
  • extract：返回列表中指定位置的值。
    • 参数 list：逗号或空格分隔的值列表。
    • 参数 index：数字，指定要返回的列表元素位置，从 1 开始。
  • range：生成一系列值的列表。
    • 参数 start（可选）：起始值，默认 1。
    • 参数 end：结束值。
    • 参数 step（可选）：递增间隔。
  • each：将列表中的元素依次绑定给规则中的每一项。
    • 参数 list：逗号或空格分隔的值列表。
    • 参数 rules：匿名规则集或混合。

数学函数

  • ceil：向上取整。
  • floor：向下取整。
  • percentage：将浮点数转换为百分比字符串。
  • round：四舍五入。
    • 参数 number：浮点数。
    • 参数 decimalPlaces（可选）：要舍入到的小数位数，默认 0。
    • 返回：number。
  • sqrt：计算数字的平方根，单位不变。
  • abs：计算数值的绝对值，单位不变。
  • pi：返回 π。
  • pow：返回参数的幂，幂为第二个参数。
  • min：返回一个或多个值中的最小值。
  • max：返回一个或多个值中的最大值。

类型函数

  • isnumber：判断值是否为数字，返回 true 或 false。
  • isstring：判断值是否为字符串，返回 true 或 false。
  • iscolor：判断值是否为颜色值，返回 true 或 false。
  • iskeyword：判断值是否为 keyword，返回 true 或 false。
  • isurl：判断值是否为 url()，返回 true 或 false。
  • isunit：判断值是否为指定单位的数字，返回 true 或 false。
    • 参数 value：要评估的值。
    • 参数 unit（可选）：要测试的单位标识符。

杂项函数

  • image-size：从文件中获取图像大小，目前仅在 Node 环境中可用。
  • image-width：从文件中获取图像宽度，目前仅在 Node 环境中可用。
  • image-height：从文件中获取图像高度，目前仅在 Node 环境中可用。
  • convert：转换单位，只转换兼容的单位；单位不兼容时返回第一个参数。
    • 参数：带单位的数字、目标单位。

示例：

兼容的单位组：

  • 长度：m、cm、mm、in、pt、pc
  • 时间：s、ms
  • 角度：rad、deg、grad、turn

色彩操作功能

  • fadein：降低颜色的透明度（或增加不透明度），使其更加不透明。
  • fadeout：增加颜色的透明度（或降低不透明度），使其不那么不透明。
    • 参数 color：颜色对象。
    • 参数 amount：百分比，0–100%。
    • 参数 method（可选）：设为 relative 时相对于当前值调整。
  • mix：将不同比例的颜色混合在一起。
    • 参数 color1：颜色对象。
    • 参数 color2：颜色对象。
    • 参数 weight（可选）：两种颜色之间的百分比平衡点，默认 50%。
  • shade：以可变比例将颜色与黑色混合。

注意点

  • 单行注释 // 不会输出到 CSS；需要保留到产物的注释应使用 /* */。
  • 混合函数按参数顺序传值，带默认值的参数可以省略。
  • if 的 condition 在 Less 3.6 之前必须用括号包起来。
  • image-size、image-width、image-height 依赖 Node 环境，浏览器端无法使用。
  • convert 只处理兼容单位，跨单位组会原样返回第一个参数。
