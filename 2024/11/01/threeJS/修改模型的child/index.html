这篇以 3D 贺卡为例，讲清楚 GLTF 模型加载之后能做什么：拿到 gltf.scene 作为模型根节点，按比例缩放，遍历子节点修改可见性或材质；再叠加平行光、点光源组、水面、相机切屏和实例化星星，把静态模型改造成完整的交互场景。

场景说明

贺卡是一个 GLTF 模型，模型内部由多个部件组成，需要按部件名称控制显示效果。场景还需要灯光和阴影来表现纸张质感，水面和星空负责氛围，滚轮切换文字页时相机跟着移动到对应位置。

第一步：在加载回调中取得模型场景

加载模型后通过回调函数来设置模型，回调参数 gltf 上的 scene 就是模型的根节点。

第二步：设置模型缩放

用 scale.set 一次性设置三个轴的缩放比例，让模型大小适配场景。

这里的 x、y、z 是占位，需要按模型实际尺寸填写具体数值。

第三步：遍历模型取得各个部件

traverse 会递归遍历模型的所有子节点，回调里的 child 就是每一个部件。可以读取它的网格、名称，也可以控制是否渲染。

注：Mesh 是由几何体和材质组成的网格，而网格才能渲染在屏幕上。

第四步：把模型添加到场景

前面的遍历和修改只是准备工作，最后必须把模型根节点加入场景，模型才会真正渲染，这一步最重要。

基础变换语法

设置模型或网格的位置（position）

位置可以直接 set，也可以单独改某个轴，或者整体赋一个新的三维向量。

设置物体旋转（rotation）

rotation 表示的是绕 x、y、z 轴旋转的弧度。

设置相对于原位置的移动距离（translate）

translate 的用法和 position 类似，区别是它在当前位置上继续移动，而不是直接指定坐标。

平行光（DirectionalLight）/ 直射光

它模拟阳光，场景中使用了物理材质时一定要有。创建后把光源加入场景即可生效。

点光源

点光源的作用类似于给屋子亮灯：屋子开了个门，门口会投射出灯光。先创建点光源，再适当调整位置。

开启点光源的阴影投射。

同时要让渲染器允许光源产生阴影。

最后在模型中设置允许接收阴影和投射阴影，并把光源添加到场景中。

创建一个点光源组

这是一个由球体装载点光源的组。先创建组并调整组的位置。

设置球体半径、准备一个空数组，然后通过循环产生 n 个球体光源。

设置球体的位置，在球体中添加点光源，然后把球体添加到组中。

在场景中添加点光源组。

用补间动画旋转光源组并上下移动

用 gsap 让角度从 0 转到 2π，在每一帧的 onUpdate 里同时更新组的旋转和每个球体的位置，其中 y 轴叠加了角度的五倍，形成上下起伏。

水面

先引入水的模型包。

创建一个圆的平面，半径和分段数按场景尺寸填写。

用平面几何体创建水面，并配置画布尺寸、颜色、流向和波纹尺度。

水面创建出来默认垂直于模型，需要绕 x 轴旋转 90 度放平，再添加到场景中。

相机位置与文字切屏

用补间动画移动相机：

  • 调用 gsap 的 timeline() 创建两个变量。
  • 封装一个相机移动函数，用这两个变量分别控制相机要移动的位置和聚焦，并设置 x、y、z、duration 和 ease。
  • 写一个对象数组，其中包含文本信息和回调函数；回调函数里调用相机移动函数，并传入坐标。
  • 监听鼠标滚轮事件，判断滚轮是否向下滚动：
    • 是，变量加一并判断，只有当变量小于对象数组长度减一时才加一，否则归零。
    • 否，直接调用对象数组中当前变量对应对象的回调函数。
    • 建议增加防抖：防抖变量为 true 时直接返回，鼠标滚动时延时一定时间再让防抖变量变为 false。
  • 最后在页面中遍历展示文本，最外层通过修改 translate3d 控制滚轮滚动时文本页跟着移动。

创建漫天星星

通过 InstancedMesh 创建 100 个以上的球的实例，并随机分配到天上。整体流程如下：

  • 创建开始位置和结束位置两个空数组。
  • 通过 for 循环获取随机的 x、y、z，并添加到开始数组中。
  • 创建一个矩阵，设置位置，再设置实例的矩阵。
  • 把实例添加到场景中。
  • 使用贝塞尔曲线画爱心路径，并根据路径调用 getPoint 取点。
    • 通过 for 循环获取曲线的每一个点并添加到结束数组；如果图形太大，可以给 x、y 乘以一个小数。
  • 创建爱心动画：
    • 定义一个参数，起始时间设为 0。
    • 使用补间动画从 0 执行到 1；在更新时实时计算“开始数组的当前位置 +（结束位置 - 开始位置）× 参数”，得到当前插值位置。
    • 创建一个矩阵，设置位置，然后设置实例的矩阵。
    • 设置实例矩阵后需要标记更新。
  • 创建复原函数：和爱心动画一样，只需要把开始数组和结束数组对调。
  • 在对象数组中需要呈现的回调函数里调用爱心动画函数。
  • 在滚轮监听事件中，当变量要归零时调用复原函数。

注意点

  • child.Mesh 和 if (child.Mesh) 都不是 Three.js 的属性，Object3D 上没有 Mesh 字段。判断网格应使用 child.isMesh，否则这里的判断永远不成立，阴影和部件识别都不会生效。
  • mesh.rotation = new THREE.Vector3(x, y, z) 的类型不对：rotation 需要的是 THREE.Euler，直接赋 Vector3 会破坏旋转对象的内部结构，应改用 mesh.rotation.set(x, y, z)。
  • 点光源组的代码把 sphere.position.set(...)、sphere.add(pointLight)、pointLightGroup.add(sphere) 写在了 for 循环外面，此时 i、sphere、pointLight 都已超出作用域；这些语句应放进循环体内。
  • 补间动画里 pointLightArr 存的是球体，所以 onUpdate 改的是球体位置，点光源作为球体的子节点跟着移动，这一点与代码一致。
  • Water 的引入路径 three/examples/jsm/objects/Water2 在部分版本需要补 .js 后缀；CircleGeometry(半径,分段默认32) 和水面参数里的数值是占位或示例值。
