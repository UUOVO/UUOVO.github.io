这几种光影效果本质上只做两件事：复制一份元素做模糊或渐变，再用定位和层级把它压到主体背后或盖在主体之上。下面按彩色投影、倒影、玻璃反光、毛玻璃四个案例拆开，每个案例都能独立复制使用。

背景：四个案例的共同思路

  • 彩色投影：把背景色复制一层，模糊后垫在盒子下面。
  • 倒影：把元素镜像翻转后挂在下方，或用滤镜属性一步完成。
  • 玻璃反光：在图片上盖一个与图片等大的容器，用伪元素做一条 45deg 的半透明光带并让它循环扫过。
  • 毛玻璃：用背景滤镜模糊掉元素背后已经渲染的内容。

方式一用”父子两层”实现：父元素提供相对定位和背景色，子元素绝对定位、继承背景色，模糊后通过负的 z-index 垫到下面。

注意点

  1. 方式一的片段里 background: ''; 不是合法 CSS 值，只是占位，实际要写具体颜色（完整示例里用的是 #bfa）。
  2. 彩色投影方式一依赖子元素比父元素大并且 z-index: -1，如果父元素没有形成层叠上下文，z-index: -1 会让投影跑到父元素背景之外甚至被其他元素遮住。
  3. -webkit-box-reflect 只在 WebKit/Blink 内核可用，Firefox 需要用伪元素 + transform 的方案兜底。
  4. backdrop-filter 模糊的是元素背后的内容，元素自身背景是纯色不透明时就看不到效果，通常要配合半透明背景使用。
  5. 光带的 width: 1200px 明显大于容器宽度，是靠容器的 overflow: hidden 裁掉的，去掉 overflow: hidden 会看到光带溢出国图片。
  6. 示例中的 @keyframes 写在 .pili 内部，这是 SCSS 的嵌套能力，纯 CSS 文件不能这样嵌套。
