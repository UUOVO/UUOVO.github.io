这篇把 ECharts 的落地路径压缩成一条线：先装包、引入、在 React 里初始化并拿到正确的宽高，再逐项处理尺寸、背景、颜色、图例和自定义图形，最后按柱状图、折线图、饼图、关系图、雷达图、联动图分类型给出常用配置。按顺序读能搭出一个可运行的图表，当速查表用也可以直接跳到对应小节。

背景

画一张 ECharts 图通常只有四件事：容器有尺寸、实例只初始化一次、option 描述视觉、事件处理交互。真正卡住开发的往往是细节——容器宽高取不到、颜色和 label 对不上、图例点击后拿不到状态。下面按「接入 → 通用配置 → 具体图表类型」的顺序展开。

ECharts 本身只能使用静态背景，不能直接给它挂动态背景。做法是在应用 ECharts 的容器的父容器上添加背景，父容器用动态背景即可。

第七步：legend 图例

什么时候展示

当 data 中的数据带有 name 属性时才会展示图例。

控制图例的位置

  • top 和 left：决定图例位于图表的哪个位置
  • orient：'vertical' 或 'horizontal'，决定图例是垂直还是水平排列

修改每一项的间隔和样式

  • itemGap：控制图例每项的间隔
  • itemWidth 和 itemHeight：控制图例图形大小
  • itemStyle：控制图形的样式

图例的关闭与交互

  • selectedMode：控制是否可点击图例，也可以设置为 'single' 或 'multiple' 的选择模式
  • inactiveColor：关闭图例后的颜色

踩坑与注意点

  1. 初始化前要保证容器已有宽高，否则会渲染成空白；同一容器重复 init 会提示实例已存在，处理方式见《echart 问题与解答》。
  2. 当 itemStyle 的 color 配置成渐变后，label 的 color 无法通过回调映射到渐变颜色，需要在数据项中单独配置。
  3. 动态背景只能加在父容器上，ECharts 自身只支持静态背景。
  4. 图例不显示时，先检查 data 中的数据有没有 name 属性。
